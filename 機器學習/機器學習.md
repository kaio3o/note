# 機器學習的流程
1. 原始資料集匯入
2. 原始資料集預處理與探索([[特徵工程]])
3. 選擇演算法
4. 模型評估與改善
	1. 回歸問題(預測連續數值) 使用MSE(均方誤差)、R Squared，分類問題(預測類別) 使用混淆矩陣
	2. 判斷是否overfitting 或underfitting- K折交叉驗證(K-fold Cross-Validation) + 學習 曲線(Learning Curve)
	3. 正規化(Rugularization)，損失函數
		- L1 正規化：將不重要特徵壓縮至0
		- L2 正規化：讓權重變小

## 集群分析法
### 切割式分群
K-Means K為隨機初始點
K-means++ K找距離較遠為中心點
找K值方法
-  手肘方法(The elbow Method)
-  輪廓係數法，凝聚度小(與其他群)、分離度高(不同群)
### 階層式分群
-  不確定分幾群時
-  為了解資料的層次結構
-  需要可視化的分群結果
1. 聚合式階層分群法
	群由小變大 (合併)
2. 分裂式階層分群法
	群由大變小 (分裂)
