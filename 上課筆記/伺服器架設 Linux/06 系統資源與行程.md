# 系統資源與行程

## 觀察方向

CPU、記憶體、磁碟 I/O 與行程狀態是基本排查面向。

```bash
top
free -h
uptime
ps aux
ps -ef --forest
pgrep process_name
kill -TERM PID
kill -KILL PID
```

## 排查流程

1. 用 `uptime`、`free -h`、`df -h` 判斷資源類型。
2. 用 `top`／`ps` 找出高耗用行程。
3. 確認行程後先用 `TERM` 優雅停止，最後才考慮 `KILL`。
