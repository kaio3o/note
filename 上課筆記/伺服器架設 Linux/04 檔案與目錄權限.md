# 檔案與目錄權限

## 權限表示

```text
-rwxr-x---
  ||| |||
  ||| ||+-- 其他使用者
  ||+------ 群組
  +-------- 擁有者
```

- 檔案：`r` 讀取、`w` 寫入、`x` 執行。
- 目錄：`r` 列出內容、`w` 新增／刪除項目、`x` 進入或存取項目。
- 數字權限：`r=4`、`w=2`、`x=1`，例如 `755` 等於 `rwxr-xr-x`。

```bash
ls -l file
chmod 640 file
chmod u+x script.sh
chown user:group file
chgrp group file
umask 027
```

> 權限設定應遵守最小權限原則，不要為了方便直接使用 `chmod 777`。

## 從零開始理解

權限的目的，是決定「誰可以對什麼做什麼」。執行：

```bash
ls -l report.txt
```

可能看到：

```text
-rw-r----- 1 alice developers 1200 Oct 23 10:00 report.txt
```

讀法如下：

- 第一個字元 `-`：這是一般檔案；`d` 則是目錄。
- `rw-`：擁有者 alice 可以讀、寫，不能執行。
- `r--`：developers 群組只能讀。
- `---`：其他人沒有權限。
- `alice developers`：擁有者與群組。

### 數字權限怎麼算？

`r=4`、`w=2`、`x=1`，把三種權限相加：

- `7 = 4+2+1 = rwx`
- `6 = 4+2 = rw-`
- `5 = 4+1 = r-x`
- `0 = ---`

所以 `chmod 640 report.txt` 表示擁有者可讀寫、群組可讀、其他人無權限。

### 檔案與目錄的 x 不一樣

對檔案而言，`x` 通常表示可以執行；對目錄而言，`x` 表示可以穿越或進入。即使目錄可以列出內容，沒有 `x` 仍可能無法讀取裡面的檔案。

```bash
mkdir private
touch private/note.txt
chmod 700 private
ls -ld private
```

### 建議的檢查順序

```bash
ls -l file
namei -l /path/to/file
id
getfacl file
```

先看檔案本身，再看每一層父目錄，最後確認目前使用者與 ACL。

> [!warning] `chmod 777` 的問題
> 它讓所有人都能讀、寫、執行，常常只是掩蓋真正的擁有者或群組設定錯誤。應先用 `chown`、`chgrp` 或 ACL 解決。
