## LAB 1：大量建立使用帳號

原始頁面：[NTUB 練習：大量建立使用帳號](https://hackmd.io/@ntub-class/B12EXeiufx/%2FbOiAZwkrR_Ob0AkUkCUqtQ)

### 1. 建立測試目錄與帳號清單

```bash
mkdir lab1/
cd lab1/
vi userlist
```

每行格式為：

```text
使用者名稱:密碼:UID:GID:說明:家目錄:登入Shell
```

原課程示例：

```text
stu001:P@ssw0rd:1101:1001::/home/stu001:/bin/bash
stu002:P@ssw0rd:1102:1001::/home/stu002:/bin/bash
stu003:P@ssw0rd:1103:1001::/home/stu003:/bin/bash
stu004:P@ssw0rd:1104:1001::/home/stu004:/bin/bash
```

先確認帳號不存在：

```bash
id stu001
id stu002
grep 'stu00' /etc/passwd
grep 'stu00' /etc/shadow
```

### 2. 批次建立

```bash
newusers < userlist
grep 'stu00' /etc/passwd
grep 'stu00' /etc/shadow
id stu001
```

`newusers` 會讀取標準輸入；`< userlist` 是輸入重導。建立後應檢查 UID、主要群組、家目錄與 shell：

```bash
getent passwd stu001
ls -ld /home/stu001
```

### 3. 測試登入

```bash
su - stu001
# 輸入 stu001 的密碼
whoami
pwd
exit
```

### 4. 批次修改密碼

建立 `newpass.txt`：

```text
stu001:P@ssw0rd2022
stu002:P@ssw0rd2022
stu003:P@ssw0rd2022
```

執行：

```bash
grep 'stu00' /etc/shadow
cat newpass.txt | chpasswd
grep 'stu00' /etc/shadow
```

安全改寫：避免讓密碼檔留在磁碟上，並限制權限：

```bash
chmod 600 newpass.txt
chpasswd < newpass.txt
shred -u newpass.txt
```

實驗環境才可使用示範密碼；正式環境應採用互動輸入、隨機密碼或集中式身分管理。

### 5. 移除使用者

原課程示範兩種差異：

```bash
ls -ld /home/stu001
userdel stu001
ls -ld /home/stu001
rm -rf /home/stu001
```

```bash
ls -ld /home/stu002
userdel -r stu002
ls -ld /home/stu002
```

`userdel` 預設不一定刪除家目錄；`userdel -r` 會同時移除家目錄與郵件佇列。正式環境請先確認資料歸屬與備份。

## LAB 2：用戶與群組

原始頁面：[NTUB 練習：用戶與群組](https://hackmd.io/@ntub-class/B12EXeiufx/%2FL4IVuKYmQwy1lZd4Y5pyeg)

### 1. 建立群組

```bash
sudo su -
groupadd class
groupadd it
groupadd acc
```

### 2. 建立使用者並指定主要群組

```bash
useradd -g class alex
useradd -g class bob
useradd -g class judy
```

較完整的實務寫法：

```bash
useradd -m -s /bin/bash -g class alex
```

### 3. 加入附加群組

```bash
gpasswd -a bob it
gpasswd -a alex it
gpasswd -a judy acc
gpasswd -a alex acc
```

驗證：

```bash
id alex
id bob
id judy
getent group class
getent group it
getent group acc
```

注意：`-g` 是主要群組；`gpasswd -a` 或 `usermod -aG` 才是追加附加群組。使用 `usermod -G` 時若漏掉 `-a`，可能會覆蓋原本的附加群組。

## LAB 3：找出忙碌行程

原始頁面：[NTUB 練習：找出忙碌行程](https://hackmd.io/@ntub-class/B12EXeiufx/%2FVQtYqvOZSU63LYtV1Ow5yA)

使用 batch 模式讓 `top` 輸出可以被管線處理：

```bash
top -b -n 1 | grep -A 3 'PID' | tail -n 3
top -b -n 1 | head -n 10 | tail -n 3
```

參數：

- `-b`：非互動 batch 模式。
- `-n 1`：只取一輪更新。
- `grep -A 3`：找到標題後再顯示後面 3 行。
- `head -n 10`、`tail -n 3`：截取輸出範圍。

更實用的排序方式：

```bash
ps -eo pid,user,pcpu,pmem,comm --sort=-pcpu | head
ps -eo pid,user,pcpu,pmem,comm --sort=-pmem | head
```

先找出 PID，再用 `ps -p` 交叉確認：

```bash
ps -p <PID> -o pid,ppid,user,stat,pcpu,pmem,cmd
```

## LAB 4：中斷行程

原始頁面：[NTUB 練習：中斷行程](https://hackmd.io/@ntub-class/B12EXeiufx/%2FQjQWMEGfRtaG1R5afnf93Q)

### 1. 建立高 CPU 測試腳本

請在測試 VM 開啟兩個 Terminal。Terminal-1：

```bash
vi run.sh
```

內容：

```bash
#!/bin/bash
c=0
while true; do
    ((c++))
    echo $c
done
```

執行：

```bash
chmod +x run.sh
./run.sh
```

這個無限迴圈會持續輸出並消耗 CPU；不要在正式主機執行。

### 2. 用 top 找出行程

Terminal-2：

```bash
top
```

在 `top` 中可按 `k`，輸入目標 PID，再輸入訊號 `15`（SIGTERM）要求行程正常結束。確認 Terminal-1 是否停止。

### 3. 用 ps 與 kill 結束

再次執行 `./run.sh`，另開 Terminal：

```bash
ps auxf | grep '[r]un.sh'
kill -TERM <PID>
ps -p <PID>
```

若程序沒有正常結束，先查明原因，再考慮：

```bash
kill -KILL <PID>
```

`SIGTERM` 允許程式清理資源；`SIGKILL` 不能被程式攔截，應只作最後手段。原始課程寫法中的 `kill {PID}` 應替換成實際數字 PID。
