# 檔案與目錄操作

| 指令 | 用途 | 例子 |
|---|---|---|
| `pwd` | 顯示目前目錄 | `pwd` |
| `ls` | 列出檔案 | `ls -lah` |
| `cd` | 切換目錄 | `cd /etc` |
| `cp` | 複製 | `cp source target` |
| `mv` | 移動／重新命名 | `mv old new` |
| `rm` | 刪除 | `rm -i file` |
| `mkdir` | 建立目錄 | `mkdir -p a/b` |
| `touch` | 建立空檔／改時間 | `touch file` |
| `cat` | 輸出內容 | `cat file` |
| `less` | 分頁檢視 | `less file` |
| `head`／`tail` | 查看開頭／結尾 | `tail -f app.log` |
| `grep` | 過濾文字 | `grep -n error app.log` |

## 注意事項

- `rm -f` 不會詢問，使用前先確認路徑。
- `ls -l` 會顯示權限、連結數、擁有者、群組、大小、修改時間與名稱。
- `less` 中可用 `q` 離開、`/關鍵字` 搜尋、`n` 跳下一個結果。

## 從零開始理解：Linux 把所有東西都當成檔案

Linux 使用類似樹狀結構的檔案系統，最上層是 `/`，不是 Windows 的 `C:\`。常見目錄包括：

- `/home`：一般使用者的家目錄。
- `/etc`：系統設定檔。
- `/var/log`：會持續增加的資料，例如日誌。
- `/tmp`：暫存資料。
- `/usr/bin`：許多一般指令的位置。

### 相對路徑與絕對路徑

`/etc/hosts` 是從根目錄開始的絕對路徑；`../logs/app.log` 是相對於目前目錄的路徑。執行任何複製或刪除前，先確認位置：

```bash
pwd
ls -la
cd /tmp
pwd
cd -
```

### 一個完整的安全練習

```bash
mkdir -p ~/linux-practice/source
cd ~/linux-practice
echo 'hello linux' > source/message.txt
cp -i source/message.txt copy.txt
mv copy.txt renamed.txt
cat renamed.txt
rm -i renamed.txt
```

這裡的 `>` 會建立或覆寫檔案；`cp -i` 和 `rm -i` 會在可能覆寫或刪除時詢問。

### 搜尋的思考方式

- 已知檔名、不知道在哪裡：`find`。
- 已知文字、不知道在哪個檔案：`grep`。
- 檔案很長，只想看一小段：`head`、`tail`。
- 想邊看邊等新日誌：`tail -f`。

```bash
find ~/linux-practice -type f -name '*.txt'
grep -RIn 'hello' ~/linux-practice
```

> [!warning] 刪除前的三問
> 我目前在哪裡？目標是不是我想刪的？是否有備份？初學時優先使用 `rm -i`，不要直接使用未確認的 `rm -rf`。
