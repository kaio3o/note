# 檔案與目錄操作

| 指令 | 用途 | 例子 |
|---|---|---|
| `pwd` | 顯示目前目錄 | `pwd` |
| `ls` | 列出檔案 | `ls -lah` |
| `cd` | 切換目錄 | `cd /etc` |
| `cp` | 複製 | `cp source target` |
| `mv` | 移動／重新命名 | `mv old new` |
| `rm` | 刪除 | `rm -i file` |
| `mkdir` | 建立目錄 | `mkdir -p a/b` |
| `touch` | 建立空檔／改時間 | `touch file` |
| `cat` | 輸出內容 | `cat file` |
| `less` | 分頁檢視 | `less file` |
| `head`／`tail` | 查看開頭／結尾 | `tail -f app.log` |
| `grep` | 過濾文字 | `grep -n error app.log` |

## 注意事項

- `rm -f` 不會詢問，使用前先確認路徑。
- `ls -l` 會顯示權限、連結數、擁有者、群組、大小、修改時間與名稱。
- `less` 中可用 `q` 離開、`/關鍵字` 搜尋、`n` 跳下一個結果。
