## 一、套件與網路設定（對應 [[10 RPM 與 dnf 套件管理]]、[[09 網路工具與組態]]）

### Q1 查詢 httpd 套件用 `sudo dnf list httpd`，要如何安裝？
```bash
sudo dnf install httpd
```
加 `-y` 可以跳過「確定要安裝嗎？[y/N]」的詢問：`sudo dnf install -y httpd`。
> [!tip] 標準流程
> `dnf list` 查有沒有 → `dnf install` 裝 → `rpm -q httpd` 確認裝好了 → `systemctl enable --now httpd` 啟動。

### Q2 如何移除 httpd 套件？
```bash
sudo dnf remove httpd
```
`erase` 與 `remove` 等價。dnf 會一併把「只有它在用」的相依套件列出來問你，看清楚再按 y。

### Q3 設定 IP 資訊，用 root 身份執行什麼指令？
```bash
sudo nmtui        # 文字選單介面（最適合上課）
# 或指令式
sudo nmcli connection modify ens160 ipv4.method manual ipv4.addresses 192.168.1.11/24 \
     ipv4.gateway 192.168.1.1 ipv4.dns 168.95.1.1
sudo nmcli connection up ens160
```
重點：改完要**重新啟用連線**（nmtui 的「啟用連線」先停用再啟用，或 `nmcli connection up`）才會生效。

### Q4 在 Windows 要顯示「控制台\所有控制台項目\網路連線」，用什麼指令？
```text
ncpa.cpl
```
按 `Win + R` 輸入 `ncpa.cpl` 即可（Network Connections Panel）。要看 IP 資訊則用 `ipconfig /all`。

### Q5 從 `ip a` 的結果看，`ens160` 和 `ens192` 哪張網卡對應到 NAT？
**這題要看你的 `ip a` 截圖，沒辦法憑空回答**，但判斷方法固定：
1. 記下兩張網卡各自的 **IP 網段**與 **MAC**。
2. 在 VMware 的「虛擬網路編輯器」看 **VMnet8（NAT）** 的子網路（常見 `192.168.x.0/24`，由 VMware 隨機產生）；**Host-only** 是 VMnet1，**橋接**則是跟你實體網路同網段。
3. 網段對得上 VMnet8 的那張就是 NAT。也可以在 VM 設定裡看每張網路介面卡的 MAC，對照 `ip a` 的 `link/ether`。

> [!note] 經驗法則
> 先加進 VM 的網卡通常編號較小（`ens160`），之後加的是 `ens192`，但**不要只靠編號猜**，一定用網段或 MAC 驗證。

## 二、主機名稱與檔案基本操作（對應 [[02 檔案與目錄操作]]）

### Q6 儲存本地主機名稱的設定檔是什麼？要讓提示字元從 `[student@localhost ~]$` 變成 `[student@Server1 ~]$` 該改哪個檔？
設定檔是 **`/etc/hostname`**。

```bash
sudo hostnamectl set-hostname Server1   # 推薦：直接寫入 /etc/hostname 並立即生效
# 或手動：sudo vi /etc/hostname，內容改成 Server1
```
提示字元是登入時才讀主機名稱，所以要**登出再登入**（或開新的終端機）才會看到 `[student@Server1 ~]$`。

### Q7 `touch` 除了更新現有檔案/目錄的時間戳記，還有什麼功能？
**檔案不存在時，會建立一個大小為 0 的空檔案。** 這也是 `touch` 最常被用來「快速建立測試檔」的原因。

另外還可以用 `-t`、`-d` **指定任意時間**，而不只是「現在」：
```bash
touch newfile                       # 不存在就建立空檔
touch -d "2026-01-01 08:00" newfile # 指定時間
```

### Q8 顯示檔案詳細屬性（大小、Inode、SELinux Context、時間戳記等），`XXXXX /etc/passwd` 的指令為何？
```bash
stat /etc/passwd
```
`stat` 一次列出大小、inode、權限、擁有者、SELinux context，以及 Access／Modify／Change 三種時間。`ls -l` 只看得到其中一部分。

### Q9 如何把 `ls -X a/` 改成遞迴列出目錄與子目錄結構？
```bash
ls -R a/        # -R = recursive 遞迴
ls -XR a/       # 保留 -X（依副檔名排序），再加 -R
```
想看成「樹狀」可以用 `tree a/`（需 `sudo dnf install tree`）。

### Q10 `history` 第 18 行是 `mkdir -p a/b/c/d/e/f`，如何快速再跑一次？
```bash
!18
```
`!數字` 重跑指定編號的歷史指令；`!!` 是重跑上一條；`!mkdir` 是重跑最近一條以 mkdir 開頭的指令。

### Q11 把 `sample1` 內容的 `:` 改成 `,`，**同時直接寫入該檔案**，如何修改 `sed -e 's/:/,/g' sample1`？
```bash
sed -i 's/:/,/g' sample1
```
- 沒有 `-i`：只把結果**印在螢幕**，原檔不動。
- 有 `-i`（in-place）：**直接改檔案**。
> [!warning] 保險做法
> 第一次用 `-i` 前先不加 `-i` 預覽，或用 `sed -i.bak ...` 自動留一份 `sample1.bak` 備份。

### Q12 如何修改 sed 指令，把 `sample1` 中包含 `sync` 的行刪除並寫入檔案？
```bash
sed -i '/sync/d' sample1
```
`/sync/` 是比對「含有 sync 的行」，`d` 是 delete。

### Q13 編輯腳本 `/opt/hello` 後，要能執行 `sudo /opt/hello`，需要如何修改檔案屬性？
**給執行權限（x）：**
```bash
sudo chmod +x /opt/hello      # 所有人可執行
sudo chmod 755 /opt/hello     # 等價寫法（rwxr-xr-x）
```
另外腳本第一行建議寫 `#!/bin/bash`（shebang），系統才知道用誰來執行。
`sudo /opt/hello` 是用**完整路徑**執行，所以不用在 PATH 裡；若直接打 `hello` 才需要放進 PATH 內的目錄。

### Q14 要顯示環境變數 PATH 的內容，如何修改指令 `sudo echo`？
```bash
echo $PATH
```
不需要 `sudo`，也不能忘了 `$`（沒有 `$` 只會印出字面的 `PATH`）。也可以用 `printenv PATH`。
> [!note] 觀念
> `sudo echo $PATH` 的 `$PATH` 是**你目前的 shell 先展開**再交給 sudo，所以印出來的仍是你自己的 PATH；而且 `sudo` 本身會用 `secure_path`，兩者可能不同。

## 三、使用者與權限（對應 [[03 使用者與群組]]、[[04 檔案與目錄權限]]）

### Q15 大量建立使用者帳號與批次更新密碼的流程為何？
**方法 A：`newusers`（一次建帳號＋密碼）**
```bash
# users.txt 每行 7 欄，格式同 /etc/passwd：帳號:密碼:UID:GID:說明:家目錄:shell
# 例：  s01:Pass1234:2001:2001:student01:/home/s01:/bin/bash
sudo newusers users.txt
```

**方法 B：`useradd` 迴圈建帳號，再用 `chpasswd` 批次改密碼**
```bash
for u in s01 s02 s03; do sudo useradd "$u"; done
# pw.txt 每行：帳號:新密碼
sudo chpasswd < pw.txt
```
流程記法：**準備名單檔 → 建帳號（newusers 或 useradd）→ chpasswd 批次設密碼 → `getent passwd`／`id` 驗證**。
> [!warning] 注意
> 名單檔裡是**明碼密碼**，用完要刪掉（`rm users.txt pw.txt`）。

### Q16 執行 `mkdir /class/{public,grp1,grp2}` 出現 `No such file or directory`，如何修正？
原因是 **`/class` 這個上層目錄還不存在**，`mkdir` 預設不會幫你一路建上去。

```bash
sudo mkdir -p /class/{public,grp1,grp2}
```
`-p`（parents）會自動建立不存在的上層目錄。因為 `/` 底下只有 root 能寫，所以要加 `sudo`。

### Q17 如何修正 `chmod xxx`，使 public 為 `drwxrwxrwx`、grp1 為 `drwxrwx---`、grp2 為 `drwxrwxr-x`？
把每組 `rwx` 換成數字（r=4, w=2, x=1）：

| 目錄 | 權限字串 | 八進位 |
|---|---|---|
| public | `rwx rwx rwx` | **777** |
| grp1 | `rwx rwx ---` | **770** |
| grp2 | `rwx rwx r-x` | **775** |

```bash
cd /class
sudo chmod 777 public
sudo chmod 770 grp1
sudo chmod 775 grp2
ls -ld public grp1 grp2     # 驗證
```

## 四、重導向與管線（對應 [[05 訊息重導與管線]]）

### Q18 stderr(2) 轉到 stdout(1)，同時輸出到 `log.txt`，如何修改 `ls sample2 > log.txt`？
```bash
ls sample2 > log.txt 2>&1
# 或簡寫
ls sample2 &> log.txt
```
**順序很重要**：先 `> log.txt` 把 stdout 指到檔案，再 `2>&1` 讓 stderr 跟著 stdout 走。寫成 `2>&1 > log.txt` 的話，錯誤訊息仍會跑到螢幕。

### Q19 執行 `cat log.txt > log.txt` 的結果為何？
**`log.txt` 會變成空檔案（內容被清空）**，新版 cat 還會報 `cat: log.txt: input file is output file`。

原因：shell 會**先**處理 `> log.txt`，在 cat 開始讀之前就把檔案截斷成 0 byte，cat 只能讀到空內容。
> [!tip] 要「原地修改」檔案的安全做法
> 用 `sed -i`、`sort -o file file`，或先輸出到暫存檔再 `mv`。

## 五、行程與資源（對應 [[06 系統資源與行程]]）

### Q20 `top -b -n 1 | head -n 8 | tail -n 1` 能找出最吃資源的 1 支程式，如何改成前 3 支？
```bash
top -b -n 1 | head -n 10 | tail -n 3
```
`top` 輸出前 7 行是摘要與欄位標題，**第 8 行才是第一支程式**。所以：第 8 行起算 3 行 → 取到第 10 行 → `head -n 10 | tail -n 3`。
`-b` 是批次模式（可接管線），`-n 1` 是只更新一次。

### Q21 要瞭解行程的上下層級（樹狀）關係，如何修改 `sudo ps aux`？
```bash
ps auxf          # f = forest，用 ASCII 畫出父子樹
ps -ef --forest  # 另一種寫法
pstree -p        # 專門畫樹狀，-p 顯示 PID
```

### Q22 可用什麼指令找出程式的 PID？
```bash
pgrep httpd              # 依名稱找 PID（最簡單）
pidof sshd               # 依程式名稱找
ps aux | grep httpd      # 傳統做法（注意會多抓到 grep 自己）
```

### Q25 行程 CPU 使用率為 53.5%，要篩出該 PID（1559），`ps aux | awk '$3 >= XX {print $2}'` 中的 XX 該怎麼設？
`ps aux` 第 3 欄是 `%CPU`，第 2 欄是 PID。要讓 53.5 通過條件，XX 只要 **≤ 53.5**，而且要比其他程式的 CPU 高才能「只挑到它」，所以設成：

```bash
ps aux | awk '$3 >= 53 {print $2}'      # XX = 53（53.5 也可以）
```
> [!warning] 別設太低
> 例如設 `>= 5` 會把其他也超過 5% 的程式一起抓出來，下一題的 kill 就會誤殺。

### Q26 承上題，如何把篩出的 PID 直接結束（kill）？
```bash
kill $(ps aux | awk '$3 >= 53 {print $2}')
# 或用 xargs
ps aux | awk '$3 >= 53 {print $2}' | xargs kill
```
一般 `kill` 送的是 SIGTERM(15)，程式沒回應再用 `kill -9`（SIGKILL 強制）。若程式屬於其他使用者要加 `sudo`。

## 六、時間與排程（對應 [[07 時間與系統排程]]）

### Q23 執行什麼指令停止服務，可將 `timedatectl` 中的 `NTP service: active` 變成 `inactive`？
```bash
sudo systemctl stop chronyd
# 或
sudo timedatectl set-ntp false
```
`timedatectl` 顯示的 NTP service 其實就是 `chronyd` 這個服務的狀態。要**開機後也不啟動**再加 `systemctl disable chronyd`。

### Q24 如何修改 `sudo timedatectl set-timezone`，把時區改為台北時間？
```bash
sudo timedatectl set-timezone Asia/Taipei
timedatectl            # 確認 Time zone: Asia/Taipei (CST, +0800)
```
忘記時區名稱可用 `timedatectl list-timezones | grep Taipei` 查。

### Q27 使用什麼指令把目前系統時間同步寫入硬體時鐘（RTC）？
```bash
sudo hwclock -w          # = --systohc（system → hardware clock）
```
反向（硬體時鐘 → 系統時間）是 `sudo hwclock -s`（`--hctosys`）。查看用 `sudo hwclock -r`。

### Q28 即時動態監控 cron 排程日誌的指令？
```bash
sudo tail -f /var/log/cron
```
`-f`（follow）會持續印出新增的行，按 `Ctrl + C` 結束。也可以用 `sudo journalctl -u crond -f`。

## 七、磁碟與檔案系統（對應 [[08 磁碟與檔案系統]]）

### Q29 卸載 `/mydata/` 後，要測試 `/etc/fstab` 自動掛載設定是否正確，輸入什麼指令？
```bash
sudo umount /mydata      # 先卸載
sudo mount -a            # 依 /etc/fstab 掛載所有尚未掛載的項目
df -h /mydata            # 或 findmnt /mydata，確認真的掛上了
```
`mount -a` 如果沒有任何錯誤訊息，通常代表 fstab 寫對了。**一定要在重開機前先測**，fstab 寫錯可能導致開機卡在 emergency mode。

### Q30 如何把 XFS 檔案系統擴充到指定掛載點（例如 `/mydata`）？
```bash
sudo xfs_growfs /mydata
```
**參數是「掛載點」而不是裝置**。流程記法：先把底層空間加大（擴充磁碟／LV）→ `xfs_growfs <掛載點>` → `df -h` 確認。XFS 只能**擴大、不能縮小**，而且可以在掛載狀態下線上擴充。
