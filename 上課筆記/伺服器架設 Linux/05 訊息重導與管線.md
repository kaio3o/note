# 訊息重導與管線

- `stdin`：標準輸入，檔案描述元 0。
- `stdout`：標準輸出，檔案描述元 1。
- `stderr`：標準錯誤，檔案描述元 2。

```bash
command > output.txt
command >> output.txt
command 2> error.txt
command &> all.txt
command1 | command2
```

## 實用組合

```bash
ps aux | grep nginx
cat access.log | grep 404 | less
du -sh * | sort -h
```

## 從零開始理解

大部分 Linux 指令都有三條通道：

- 標準輸入 stdin（編號 0）：指令從這裡讀資料。
- 標準輸出 stdout（編號 1）：正常結果輸出到這裡。
- 標準錯誤 stderr（編號 2）：錯誤訊息輸出到這裡。

終端機只是預設把輸出顯示在螢幕上；重導可以把它改送到檔案或另一個指令。

### 覆寫與追加

```bash
echo 'first' > notes.txt
echo 'second' >> notes.txt
cat notes.txt
```

`>` 會清空原內容後重新寫入；`>>` 會保留原內容並附加到結尾。

### 分開保存錯誤

```bash
find /etc -name '*.conf' > found.txt 2> errors.txt
```

正常找到的結果放到 `found.txt`，沒有權限的錯誤放到 `errors.txt`。若要全部保存：

```bash
find /etc -name '*.conf' > all.log 2>&1
```

### 管線是在做什麼？

```bash
ps aux | grep sshd | less
```

第一個指令產生所有行程，第二個只留下含 sshd 的行，第三個讓結果可以分頁查看。管線的重點是「每個指令只做一件事，再把結果交給下一個指令」。

```bash
du -ah /var/log 2>/dev/null | sort -h | tail
```

這會忽略權限錯誤、依大小排序，最後顯示較大的項目。

> [!tip] 何時使用 tee？
> 想同時在畫面看結果，又想保存結果時使用 `tee`：`command | tee result.log`。
