# 訊息重導與管線

- `stdin`：標準輸入，檔案描述元 0。
- `stdout`：標準輸出，檔案描述元 1。
- `stderr`：標準錯誤，檔案描述元 2。

```bash
command > output.txt
command >> output.txt
command 2> error.txt
command &> all.txt
command1 | command2
```

## 實用組合

```bash
ps aux | grep nginx
cat access.log | grep 404 | less
du -sh * | sort -h
```
