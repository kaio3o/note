目的指令／關鍵點

搜尋、欄位與文字修改

grep -rinE 'error|fail' /var/log
find /etc -type f -name '*.conf'
awk -F: '{print $1}' /etc/passwd

02帳號、群組、權限

檔案用途
/etc/passwd帳號基本資料，7 欄：帳號、x、UID、GID、說明、家目錄、shell。
/etc/shadow密碼雜湊與期限；僅 root／受控程式可讀。
/etc/group群組：名稱、x、GID、附加成員。
useradd -m -s /bin/bash -g <主要群組> -G <附加群組> user
usermod -aG wheel user   # 加群組不可漏 -a
gpasswd -a user group   |   userdel -r user
newusers users.txt   |   chpasswd < pw.txt

id user 查 UID/GID/群組；su - user 載入目標登入環境；sudo cmd 以授權身分執行。批次密碼檔含明碼，練習後應刪除。

權限換算與目錄特性

數值意義常見用途
r=4, w=2, x=1依 u／g／o 三組相加644 普通檔、600 私密檔、755 腳本／公開目錄、700 私人目錄
目錄 r列出內容無 x 時可能看得到名字卻不能進入
目錄 w新增／刪除項目刪檔看父目錄權限，不只看檔案本身
目錄 x進入／穿越要存取子目錄，所有上層都需 x
chmod 640 file   |   chmod u+x script
chown user:group file   |   chgrp group file
setfacl -m u:alice:rwx dir
setfacl -d -m u:alice:rwx dir # 日後新增項目繼承

多人目錄：所有人同屬一個主要群組時，不能直接授權該群組；先 chmod -R 700 /dir，再以 ACL 對指定帳號授權，並補父目錄的 --x。

03重導、管線、文字處理

語法結果
cmd > f／>> fstdout 覆寫／追加。
cmd 2> errstderr 另存。
cmd > all 2>&1stdout 先導向 all，再讓 stderr 跟到 stdout；可寫 &> all。
cmd1 | cmd2只把 cmd1 的 stdout 給 cmd2；錯誤要先 2>&1 才會進管線。
cmd | tee log | cmd2同時顯示、存檔、往下傳遞。

陷阱：cat f > f 會先截斷輸出檔，f 變空；原地修改改用 sed -i、sort -o f f 或暫存檔＋mv。

04題庫 Q1–Q19

題庫改為分欄卡片：題意＝辨識題目；作答＝考場要輸入；提醒＝常見失分點。

Q1
題意安裝 httpd。
作答sudo dnf install httpd

Q2
題意移除 httpd。
作答sudo dnf remove httpd
先看 dnf 列出的連帶移除套件。
Q3
題意設定 IP。
作答sudo nmtui；或 nmcli con modify ... 後 nmcli con up <連線>。

Q4
題意Windows 開網路連線。
作答Win+R：ncpa.cpl

Q5
題意判斷哪張網卡是 NAT。
作答比 ip a 的 IP 網段／MAC 與 VMware VMnet8。
不可只以 ens160、ens192 編號判斷。
Q6
題意主機名設定位置與改名。
作答/etc/hostname；hostnamectl set-hostname Server1
重登入或開新終端才更新提示字元。
Q7
題意touch 其他功能。
作答不存在時建立 0 byte 空檔。
touch -d '2026-01-01 08:00' f 可指定時間。
Q8
題意看完整檔案屬性。
作答stat /etc/passwd
比 ls -l 多 inode、三種時間、context。
Q9
題意遞迴列出 a/。
作答ls -R a/；保留 X 排序：ls -XR a/
樹狀可用 tree，可能需安裝。
Q10
題意重跑 history 第 18 條。
作答!18
!! 上一條；!mkdir 最近的 mkdir。
Q11
題意sample1 的 : 改 , 且寫回。
作答sed -i 's/:/,/g' sample1
第一次可先不加 -i 預覽，或用 -i.bak。
Q12
題意刪除含 sync 的行且寫回。
作答sed -i '/sync/d' sample1
/sync/ 比對行；d 是 delete。
Q13
題意讓 /opt/hello 可執行。
作答sudo chmod +x /opt/hello 或 755
腳本首行寫 #!/bin/bash；全路徑執行不用 PATH。
Q14
題意顯示 PATH。
作答echo $PATH／printenv PATH
不可漏 $；不需 sudo。
Q15
題意批次建帳號、改密碼。
作答newusers users.txt；chpasswd < pw.txt
或 useradd 迴圈；密碼檔為明碼。
Q16
題意建 /class 三個子目錄失敗。
作答sudo mkdir -p /class/{public,grp1,grp2}
上層 /class 不存在，且 / 下需 root。
Q17
題意public/grp1/grp2 權限。
作答chmod 777 public; chmod 770 grp1; chmod 775 grp2
rwx=7；r-x=5；---=0。
Q18
題意stdout、stderr 都存 log。
作答ls sample2 >log.txt 2>&1 或 &>log.txt
順序不可寫成 2>&1 >log。
Q19
題意cat log.txt > log.txt 的結果。
作答log.txt 被清空。
Shell 先完成重導才執行 cat。

05行程、資源、時間與排程

面向指令／判讀
CPU／記憶體top（P 依 CPU、M 依記憶體排序）、free -h、uptime（1/5/15 分鐘 load average）。
行程快照ps aux；父子樹：ps auxf／ps -ef --forest／pstree -p。
找／停行程pgrep httpd、pidof sshd；先 kill -TERM PID，確認無效才 kill -KILL PID。
時間timedatectl；set-timezone Asia/Taipei；hwclock -w 系統→硬體 RTC，-s 反向。

cron分 時 日 月 週 命令；crontab -e/-l；/etc/crontab 額外有執行者欄；log：tail -f /var/log/cron。
0 2 * * * /usr/local/sbin/backup.sh >> /var/log/backup.log 2>&1
systemctl list-timers # 查 systemd timer

06磁碟、網路、套件、服務

新增磁碟與永久掛載 SOP

  1. lsblk -f：辨識裝置與既有檔案系統；題目可能有資料，不可直接 mkfs。
  2. 必要才 mkfs.xfs /dev/sdb；建掛載點 mkdir -p /data；暫掛 mount /dev/sdb /data。
  3. blkid /dev/sdb 取 UUID；fstab 加：UUID=... /data xfs defaults 0 0。
  4. mount -a 無錯，再以 findmnt /data／df -h 驗證。

XFS 擴充：先擴底層空間，再 xfs_growfs /data。XFS 只能擴，參數是掛載點。

網路診斷與設定

ip -br a → ip route → ping -c 4 <gateway> → host <name> <dns> → curl -I <URL>
nmcli con modify <連線> ipv4.method manual ipv4.addresses <IP/24> ipv4.gateway <GW> ipv4.dns <DNS> connection.autoconnect yes
nmcli con up <連線>

ss -tulpen 查監聽 port；host／dig +short 查 DNS；ping 成功不代表 HTTP 等服務可用。

套件、systemd、log、firewall

dnf search/info/install/remove；dnf provides '*/mail'；dnf repolist --all；啟 repo：dnf config-manager --set-enabled baseos。rpm -q/-qi/-ql/-qf 查已安裝／來源。

systemctl enable --now svc＝立即＋開機；status；journalctl -u svc -b -n 100 -f。防火牆永久規則：firewall-cmd --permanent --add-service=http 後 --reload。

Q20
題意top 取最吃資源前 3 支。
作答top -b -n 1 | head -n 10 | tail -n 3
前 7 行是摘要／欄位，第 8 行才是第一支程式。
Q21
題意看行程上下層樹狀關係。
作答ps auxf／ps -ef --forest／pstree -p
-p 顯示 PID，方便後續追查。
Q22
題意依名稱找 PID。
作答pgrep httpd／pidof sshd
ps aux | grep 可能抓到 grep 自己。
Q23
題意令 NTP service 變 inactive。
作答systemctl stop chronyd 或 timedatectl set-ntp false

Q24
題意改台北時區。

Q25
題意篩 CPU 53.5% 的 PID。
作答ps aux | awk '$3 >= 53 {print $2}'

Q28

Q29

08期末實作整合題

UUID 檔案、可疑行程、Swap

find /etc -type f -regextype posix-extended -regex '.*/[0-9a-f]{8}(-[0-9a-f]{4}){3}-[0-9a-f]{12}/[0-9a-f]{8}(-[0-9a-f]{4}){3}-[0-9a-f]{12}\.exam'
cp <找到的檔> /tmp/exam_file.txt

可疑行程：journalctl -f 記 PID → ps -p PID -o pid,ppid,user,cmd → ls -l /proc/PID/exe → 複製原程式到指定備份位置並取消執行權 → 在 /etc/crontab、/etc/cron.d、使用者 crontab 或 timer 找觸發項 → 停觸發、kill、刪原程式。

Swap：swapon --show 找 TYPE=file → swapoff /swapfile → 註解／刪除 /etc/fstab 對應行 → free -h 驗證。

09NFS、VirtualHost、DNS

NFS（Server2 分享、Server1 掛載）

# Server2 /etc/exports /web-roots 10.6.X.0/24(ro,sync) dnf install -y nfs-utils; systemctl enable --now nfs-server exportfs -rav # Server1 /etc/fstab 10.6.X.12:/web-roots /var/www/html nfs defaults,_netdev 0 0

Server2 防火牆開 nfs,mountd,rpc-bind；Server1 mount -a。httpd 讀 NFS：setsebool -P httpd_use_nfs 1。VirtualHost 用 /etc/httpd/conf.d/vhosts.conf，每個網域各自設定 ServerName 與 DocumentRoot；apachectl configtest 後重載／啟動。

DNS 必背

記錄用途
A／AAAA名稱→IPv4／IPv6
PTRIP→名稱（反解）
CNAME別名→正式名稱
MX／NS／TXT郵件／名稱伺服器／文字驗證或註記

改 zone 後 SOA serial +1；語法檢查：named-checkconf、named-checkzone <zone> <file>；重載：rndc reload；查詢：host -t a/txt/cname <名稱> <DNS-IP>。

指令白話詳解

檔案與文字處理｜每區固定：核心定位、參數、組合技、翻車警報
A

閱讀方式：先背「題目關鍵字 → 指令反射」，再從表格挑參數。這一段是補充頁，不取代前兩面的快速查找。

ls｜把資料夾打開，列出裡面有什麼

白話定位：等同檔案總管打開一個資料夾看檔名；加參數可切換成「詳細資料檢視」或顯示隱藏檔。考場反射：「列出、查看目錄內容、看權限／擁有者、找隱藏檔」→ ls。

參數 / 後綴英文全名 / 原意功能說明常用時機 / 效果
-llong長格式：權限、連結數、擁有者、群組、大小、時間、名稱。題目問權限、檔案屬性。
-aall連 . 開頭的隱藏檔也列出。找設定檔如 .bashrc。
-hhuman-readable大小改成 K/M/G。人眼快速看容量。
-Rrecursive連子目錄一層層列出。Q9：看完整目錄結構。
-Xextension依副檔名排序。題目保留原本 -X 再要求遞迴。
組合寫法這個組合能做到什麼事？考場題庫範例
ls -lah /etc像檔案總管詳細模式，一次看權限、隱藏檔、易讀大小。Q8 前的初步盤點。
ls -XR a/遞迴列出 a/ 下所有內容，仍依副檔名排序。Q9。

翻車警報：ls -l 只看部分資訊；題目要 inode、SELinux context、Access/Modify/Change 時改用 stat。漏 -a 看不到隱藏檔。

cd / pwd / mkdir / touch｜走到位置、確認位置、建資料夾與建空檔

白話定位：cd 是在檔案總管雙擊進資料夾；pwd 是看目前位址列；mkdir 是新增資料夾；touch 是建立空白文件或更新其時間。考場反射：「切換、目前目錄、建立多層、上層不存在、建立空檔、更新時間」→ 本組。

參數 / 後綴英文全名 / 原意功能說明常用時機 / 效果
cd ..parent回上一層。相對路徑操作。
cd -previous在目前與上一個目錄間來回跳。兩個目錄交叉操作。
mkdir -pparents父目錄不存在就一併建立；已存在不報錯。Q16、建立 a/b/c。
touch -ddate指定日期時間。測試檔案時間／題目要求改時間。
組合寫法這個組合能做到什麼事？考場題庫範例
mkdir -p /class/{public,grp1,grp2}一次建立父目錄與三個子目錄；大括號會展開成三個名稱。Q16。
cd /opt && touch hello只有成功進 /opt 才建立 hello，避免在錯誤位置建檔。腳本與練習檔操作。

翻車警報：沒有 -p 時，上層不存在會報 No such file or directory。touch 不會建立目錄；路徑末段若本來是目錄名稱，仍要先 mkdir。

cp / mv / rm / stat｜複製、搬家改名、刪除、查身分證

白話定位：cp 是複印一份；mv 是把檔案拖到別處或重新命名；rm 是永久刪除，不進資源回收桶；stat 是開啟檔案的完整身分證資料。考場反射：「複製成指定檔名、移到 PATH、刪除、inode／時間戳記」→ 本組。

參數 / 後綴英文全名 / 原意功能說明常用時機 / 效果
cp -rrecursive連資料夾與內容一起複製。複製目錄樹。
cp -aarchive盡量保留權限、時間、連結等屬性。備份／保留原樣。
-iinteractive覆寫或刪除前詢問。考場怕覆蓋指定檔。
rm -rrecursive刪除目錄及其內容。確認目標後才用。
rm -fforce不詢問，忽略不存在的檔。自動化；手動考試慎用。
組合寫法這個組合能做到什麼事？考場題庫範例
cp <找到檔> /tmp/exam_file.txt把搜尋結果複製成評分系統指定名稱。期末 UUID 檔案題。
mv /opt/exam_check_disk /usr/local/bin/把自製指令移進 PATH 目錄，之後可直接輸入指令名。期末 PATH 題。
stat /etc/passwd查大小、inode、權限與三種時間。Q8。

翻車警報：rm -rf 對錯路徑不可逆；先 pwd、ls。cp 來源為目錄卻漏 -r 會失敗。mv 同檔案系統通常是改目錄項，不是另存副本。

cat / less / head / tail｜讀內容：一次看、翻頁看、只取開頭或結尾

白話定位：cat 是一次攤開整份短文件；less 是可搜尋的閱讀器；head 只看前幾行；tail 看最後幾行，-f 像盯著即時更新的聊天室。考場反射：「log 持續監看、前 N／後 N 行、檢查設定內容」→ 本組。

參數 / 後綴英文全名 / 原意功能說明常用時機 / 效果
cat -nnumber顯示行號。指定第幾行設定時定位。
head -n Nnumber取前 N 行。從 top 輸出切出前幾名。
tail -n Nnumber取最後 N 行。搭配 head 做切片。
tail -ffollow持續印出新增行。看 cron、journal、web log。
組合寫法這個組合能做到什麼事？考場題庫範例
top -b -n 1 | head -n 10 | tail -n 3先取 top 一次快照，再從第 8 行起抓前三個行程。Q20。
tail -f /var/log/cron即時追蹤 cron 是否真的執行。Q28。

翻車警報：不可用 cat log.txt > log.txt 做複製／修改，輸出重導會先清空檔案（Q19）。大檔用 cat 會洗版，改用 less 或 head/tail。

指令白話詳解

搜尋、文字處理、帳號權限、重導與行程
B
grep / find｜先找「內容」，再找「檔案」

白話定位：grep 像在所有文件裡搜尋某段文字；find 像依檔名、類型、時間、大小到硬碟深處找檔。考場反射：「內容包含、哪個設定觸發、找 UUID 名稱／副檔名、指定天數修改」→ grep/find。
