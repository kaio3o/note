01｜ls、cd、pwd、mkdir、touch

白話定位
ls＝打開資料夾看內容；cd＝走進資料夾；pwd＝看位址列；mkdir＝新增資料夾；touch＝建立空白檔／更新時間。
題目反射：列出、隱藏檔、遞迴、建立多層、空檔、時間戳記。

參數 / 後綴英文全名 / 原意功能說明常用時機 / 效果
-llong顯示權限、擁有者、群組、大小、時間。看權限。
-aall連 . 開頭隱藏檔都列。找設定檔。
-hhuman-readable大小改 K/M/G。快速讀大小。
-Rrecursive連子目錄一起列出。Q9。
mkdir -pparents不存在的父目錄一起建；已存在不報錯。Q16。
touch -ddate指定檔案時間。時間題。
神奇組合技能做到什麼事？題庫
ls -XR a/遞迴列出 a/，維持副檔名排序。Q9
mkdir -p /class/{public,grp1,grp2}一次建立父目錄及三個子目錄。Q16
翻車警報：漏 -p，上層不存在就失敗；touch 不建目錄。題目要 inode、SELinux、三種時間用 stat，不是 ls -l。
Q6
主機名檔／改名
/etc/hostname；hostnamectl set-hostname Server1
重登入才更新提示字元。
Q7
touch 另一功能
不存在時建立 0 byte 空檔。
可用 -d 指定時間。
Q9
遞迴列 a/
ls -R a/；保留 -X：ls -XR a/
tree 可能未安裝。
Q10
重跑第 18 條 history
!18
!!＝上一條；!mkdir＝最近 mkdir。
Q16
建立 /class 子目錄
sudo mkdir -p /class/{public,grp1,grp2}
/ 下需 root。

02｜cp、mv、rm、stat、PATH

白話定位
cp＝影印；mv＝搬家或改名；rm＝永久刪除；stat＝檔案身分證。
題目反射：複製成指定名稱、移到 PATH、刪除、inode、完整屬性。

參數 / 後綴英文原意功能時機
cp -rrecursive複製目錄及內容。來源是目錄。
cp -aarchive盡量保留權限、時間、連結。備份。
-iinteractive覆寫／刪除前詢問。怕覆蓋資料。
rm -rrecursive刪整個目錄樹。確認目標後。
rm -fforce不詢問、忽略不存在。自動化，手動慎用。
神奇組合技能做到什麼事？題庫
cp <檔> /tmp/exam_file.txt複製成評分指定名稱。UUID 題
mv /opt/exam_check_disk /usr/local/bin/放入 PATH，直接輸入命令名即可。期末 PATH
stat /etc/passwd查 inode、大小、權限、時間、context。Q8
翻車警報：rm -rf 錯路徑不可逆；先 pwd、ls。來源是目錄卻漏 -r，cp 會失敗。
Q8
/etc/passwd 詳細屬性
stat /etc/passwd
ls -l 不夠完整。
Q13
讓 /opt/hello 可執行
chmod +x /opt/hello 或 755
首行 #!/bin/bash。
Q14
看 PATH
echo $PATH／printenv PATH
不可漏 $；不需 sudo。

03｜grep、find、awk、sed：找內容、找檔案、切欄位、直接改字

白話定位
grep＝文件內搜尋字；find＝依名稱、時間、類型找檔；awk＝依欄位篩選；sed＝批次取代／刪行。
題目反射：包含某字、UUID 檔、第幾欄、取代、刪 sync。

參數英文原意功能 / 時機
grep -rinEignore case / recursive / line / extended regex忽略大小寫、遞迴、行號、正規式。
find -type ffile只找一般檔案。
find -namename依 '*.log' 等檔名找。
awk -F:field separator以 : 切欄。
sed -iin place直接寫回原檔。
s/a/b/gsubstitute/global每行全部 a 改 b。
/pat/ddelete刪符合 pat 的整行。
神奇組合技能做到什麼事？題庫
grep -r '程式名' /etc/cron*找出哪個 cron 會啟動程式。可疑行程
sed -i 's/:/,/g' sample1取代且寫回。Q11
sed -i '/sync/d' sample1刪含 sync 行。Q12
ps aux | awk '$3 >= 53 {print $2}'取 CPU 第3欄≥53 的 PID 第2欄。Q25
翻車警報：find 的萬用字元加單引號，否則 shell 可能先展開。sed 漏 -i 只印螢幕。grep 找內容、find 找檔案。
Q11
: 改 , 且寫回
sed -i 's/:/,/g' sample1
可用 -i.bak 留備份。
Q12
刪含 sync 行
sed -i '/sync/d' sample1
d=delete。

04｜useradd、usermod、groupadd、chpasswd

白話定位
像公司人事：groupadd 建部門、useradd 建員工、usermod 調整群組、chpasswd 批次設密碼。
題目反射：主要群組、附加群組、多帳號、同密碼、wheel。

參數英文原意功能 / 時機
-mcreate home建 /home/帳號。
-ggroup主要群組；期末 staff/avengers。
-Ggroups附加群組。
-aGappend groups追加而不覆蓋原附加群組。
userdel -rremove home刪帳號與家目錄。
神奇組合技能做到什麼事？題庫
newusers users.txt讀 7 欄清單批次建帳號。Q15
for u in a b; do useradd -g staff $u; echo "$u:exam"|chpasswd; done建多帳號、指定主要群組與密碼。期末帳號
翻車警報：-g 是主要群組，-G 是附加群組；usermod -G 漏 -a 會覆蓋原附加群組。密碼清單是明碼。
Q15
批次建帳號／改密碼
newusers users.txt；chpasswd < pw.txt
pw.txt 格式：帳號:密碼。

05｜chmod、chown、setfacl

白話定位
chmod 改門鎖；chown 換屋主；setfacl 發給指定人的門禁卡。檔案 r=讀、w=改、x=執行；目錄 r=列、w=建刪、x=進入。
題目反射：特定幾人讀寫、其他人無權限、未來新增也要有權限。

參數英文原意功能 / 時機
chmod 755octal modeu=rwx,g/o=r-x；腳本／公開目錄。
u+xuser add execute只替擁有者加執行權。
chown u:gchange owner同時改擁有者與群組。
setfacl -mmodify加入指定帳號 ACL。
setfacl -d -mdefault modify新增內容也繼承 ACL。
神奇組合技能做到什麼事？題庫
chmod 777 public; chmod 770 grp1; chmod 775 grp2把 rwx 權限字串換八進位。Q17
setfacl -m u:tony:rwx /avenger/legal給 tony 專屬讀寫進入權。期末 ACL
翻車警報：讀寫目錄通常還需 x；要進子目錄，父目錄也需 x。chmod -R 可能把一般檔誤加 x。
Q17
三目錄權限
777／770／775
rwx=7、r-x=5、---=0。

06｜重導、管線、tee、xargs

白話定位
> 把螢幕輸出存檔；| 把前一指令結果交給下一指令；tee 同時顯示存檔；xargs 把文字變成參數。
題目反射：stderr 也存、PID 直接 kill。

語法原意功能 / 時機
>／>>redirect/append覆寫／追加 stdout。
2>stderr fd 2只導錯誤。
2>&1stderr to stdout錯誤跟 stdout 同去處。
tee -aappend顯示又追加存檔。
神奇組合技能做到什麼事？題庫
ls sample2 >log.txt 2>&1正常、錯誤訊息都進 log。Q18
ps aux | awk '$3>=53{print $2}' | xargs kill把篩出的 PID 傳給 kill。Q26
翻車警報：2>&1 必須在 >log 後；cat f > f 會先清空 f（Q19）。
Q18
stdout+stderr 同存
ls sample2 >log.txt 2>&1／&>log.txt
順序重要。
Q19
cat log > log 結果
檔案被清空。
Shell 先處理重導。

ps 是行程照片；top 是即時儀表板；kill 是寄結束訊號；timedatectl 設時鐘；cron 是定時鬧鐘。

tail -f /var/log/cron # Q28

Q20

08｜lsblk、mount、fstab、xfs_growfs、swap

白話定位
lsblk 看硬碟拓樸；mount 把磁碟接到資料夾入口；fstab 是開機自動掛載清單；xfs_growfs 擴 XFS；swapon 看交換區。
題目反射：/dev/sdb、UUID、開機掛載、XFS、停 swap。

參數英文原意功能 / 時機
lsblk -ffilesystem看 FSTYPE、UUID、掛載點。
mount -aall依 fstab 掛所有未掛項。
umountunmount卸載掛載點。
xfs_growfsgrow filesystem擴已掛載 XFS。
swapon --showshow列出 swap 與 TYPE。
神奇組合技能做到什麼事？題庫
lsblk -f → blkid /dev/sdb → 編 fstab → mount -a以 UUID 永久掛載並立即驗證。Q29
swapoff /swapfile → 註解 fstab → swapon --show立即停 swap 且重開不回來。期末 Swap
翻車警報：mkfs.xfs 會清空；題目磁碟可能有備份。xfs_growfs 參數是掛載點，不是 /dev/sdb，XFS 不能縮小。
Q29
測 fstab
umount /mydata; mount -a; df -h /mydata
重開前必測。
Q30
擴 XFS
xfs_growfs /mydata
掛載點，非裝置。

12｜期末題型：用「做完一項、驗證一項」的方式處理

可疑行程

先用 journalctl -f 記 PID；ps -p PID -o pid,ppid,user,cmd 看身分；ls -l /proc/PID/exe 找實際程式；先複製備份且取消執行權，再找 cron／timer 觸發來源，最後停觸發、kill、刪原檔。

cp -p <程式> /exam_resource/ ; chmod -x /exam_resource/<檔名>
grep -r '程式名' /etc/cron* /var/spool/cron
systemctl list-timers
只 kill 沒用；cron/timer 還會再啟動。

Web + PHP + MariaDB

dnf install -y mariadb-server httpd php php-mysqlnd php-pdo
systemctl enable --now mariadb httpd
mysql -uroot -p -e "CREATE DATABASE exam;"
mysql -uroot -p exam < /exam_resource/db_backup/file.sql

PHP 放 /var/www/html/，開 http 防火牆，再 curl 驗證。403 查權限／restorecon -Rv /var/www/html；httpd 連 DB 被擋：setsebool -P httpd_can_network_connect_db 1。

NFS + VirtualHost

# Server2 /etc/exports /web-roots 10.6.X.0/24(ro,sync) systemctl enable --now nfs-server ; exportfs -rav # Server1 fstab 10.6.X.12:/web-roots /var/www/html nfs defaults,_netdev 0 0

Apache 每個 VirtualHost 寫各自的 ServerName 與 DocumentRoot；改完 apachectl configtest。讀 NFS 被 SELinux 擋：setsebool -P httpd_use_nfs 1。

IP：ip -br a、ping -c 4 對端
