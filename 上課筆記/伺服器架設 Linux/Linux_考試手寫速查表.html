使用方式：每張指令卡都照「指令長什麼樣 → 每個參數在做什麼 → 能搭什麼組合 → 哪裡會翻車」閱讀。題目關鍵字看到「建立、找、改、權限、重導、行程、時間、磁碟、網路、套件、服務」時，直接找對應章節。

檔案與目錄

ls -l -a -h -R <目錄>｜列出內容
白話 就是檔案總管打開資料夾；加參數可改成詳細檢視、顯示隱藏檔、連子目錄一起看。
  • -l（long）：顯示權限、擁有者、群組、大小、時間。
  • -a（all）：全部列出，包含 . 開頭隱藏檔。
  • -h（human-readable）：大小顯示為 K/M/G。
  • -R（recursive）：遞迴列出包含子目錄。
  • -X（extension）：依副檔名排序。
組合 ls -XR a/：遞迴列 a/ 且按副檔名排序（Q9）。
翻車：要 inode、SELinux context、三種時間不能只用 ls，改用 stat。
cd <路徑> / pwd / mkdir -p｜移動與建資料夾
白話 cd 是走進資料夾，pwd 是看目前位址列，mkdir 是新增資料夾。
  • cd ..：回上一層；cd -：回上一個位置；cd ~：回家目錄。
  • mkdir -p（parents）：父目錄不存在就連同建立；已存在也不報錯。
  • {a,b,c}：Shell 展開，一次產生多個名稱。
組合 sudo mkdir -p /class/{public,grp1,grp2}：一次建立所有考題目錄（Q16）。
翻車：漏 -p，上層目錄不存在就失敗；/ 底下只有 root 能建立內容。
touch <檔案>｜建立空檔／更新時間
白話 像新增空白文字檔；如果檔案已存在，不改內容，只更新時間戳記。
  • -d "2026-01-01 08:00"（date）：指定時間。
  • -t YYYYMMDDhhmm（time）：以固定格式指定時間。
組合 touch newfile：建立 0 byte 測試檔（Q7）。
翻車：touch 不會建立目錄；父目錄不存在先 mkdir。
cp / mv / rm / stat｜複製、搬家、刪除、查完整屬性
白話 cp＝影印；mv＝搬家或改名；rm＝永久刪除；stat＝檔案完整身分證。
  • cp -r（recursive）：複製目錄及內容；-a（archive）：保留權限、時間等屬性。
  • -i（interactive）：覆寫／刪除前詢問；rm -f（force）：不詢問。
  • rm -r：遞迴刪除目錄。
組合 cp <找到的檔> /tmp/exam_file.txt：複製成指定名稱；mv /opt/x /usr/local/bin/：放進 PATH。
翻車：rm -rf 錯路徑不可逆；來源是目錄卻漏 -r，cp 會失敗。Q8 用 stat /etc/passwd。
cat / less / head / tail｜讀檔與看 log
白話 cat 一次攤開短檔；less 可翻頁搜尋；head 看開頭；tail 看結尾，-f 像盯即時訊息。
  • cat -n（number）：加行號。
  • head -n N／tail -n N：前／後 N 行。
  • tail -f（follow）：持續顯示新增行。
組合 top -b -n 1 | head -n 10 | tail -n 3（Q20）；tail -f /var/log/cron（Q28）。
翻車：cat log.txt > log.txt 會清空檔案（Q19）；大檔用 less，不要 cat 洗版。

搜尋、文字處理、帳號、權限、重導與管線
02
grep -r -i -n -E <模式> <路徑>｜找文字內容
白話 像在一堆文件內搜尋指定字串；找的是「內容」，不是檔名。
  • -r（recursive）：連子目錄搜尋；-i（ignore case）：忽略大小寫。
  • -n（line number）：顯示行號；-v（invert）：排除符合行。
  • -E（extended regex）：使用延伸正規表示式。
組合 grep -r '程式名' /etc/cron* /var/spool/cron：找哪個排程觸發程式。
翻車：grep 找內容，找檔名用 find；ps aux | grep httpd 會抓到 grep 自己。
find <路徑> -type f -name '模式'｜找檔案／目錄
白話 像在整顆硬碟依名稱、類型、時間、大小篩選檔案。
  • -type f（file）／-type d（directory）：限制找檔案／目錄。
  • -name '*.log'：用檔名萬用字元；要加單引號。
  • -mtime -1 / n / +n：一天內／約 n 天前／超過 n 天。
  • -regextype posix-extended -regex '...' ：用正規式比整段路徑。
組合 find /etc -type f -name '*.conf'；UUID 題改用 -regex 限制 UUID 目錄與檔名。
翻車：沒有引號時，Shell 可能先展開 *.log；find 是找檔名／路徑，不是找檔案內容。
awk -F: '{print $1}'｜按欄位取資料
白話 把每一行當成一列資料表，依分隔符切欄，再篩選／印出需要欄位。
  • -F:（field separator）：指定欄位分隔字元。
  • $1、$2、$3：第 1、2、3 欄。
  • print：印出指定欄位；>=：數值比較。
組合 ps aux | awk '$3 >= 53 {print $2}'：CPU 第3欄 ≥53，印 PID 第2欄（Q25）。
翻車：$3 是 awk 欄位；門檻設太低會選到多個 PID，Q26 可能誤殺。
sed -i 's/舊/新/g' 檔案｜取代／刪除文字
白話 像文件的「全部取代」；也可按照模式刪掉整行。
  • -i（in place）：直接寫回原檔。
  • s（substitute）：取代；g（global）：同一行全部都改。
  • /sync/d：找含 sync 的行，d（delete）刪除。
組合 sed -i 's/:/,/g' sample1（Q11）；sed -i '/sync/d' sample1（Q12）。
翻車：少 -i 只顯示結果、原檔不變；第一次可用 sed -i.bak 留備份。
useradd / usermod / groupadd / newusers / chpasswd｜帳號與群組
白話 groupadd 建部門；useradd 建帳號；usermod 調整群組；newusers/chpasswd 用名單批次處理。
  • useradd -m（create home）：建家目錄；-g：主要群組；-G：附加群組。
  • usermod -aG（append groups）：保留原附加群組再追加。
  • userdel -r：刪帳號＋家目錄。
  • chage -l：列出密碼期限。
組合 newusers users.txt；chpasswd < pw.txt（Q15）。
翻車：-g 是主要群組、-G 是附加群組；usermod -G 漏 -a 會覆蓋舊附加群組。密碼名單為明碼。
chmod / chown / chgrp / setfacl｜檔案與目錄權限
白話 chmod 改門鎖規則；chown 換屋主；setfacl 額外發給特定人的門禁卡。目錄 x=能進入／穿越。
  • r=4,w=2,x=1；chmod 755=rwx r-x r-x。
  • chmod u+x：只替擁有者加執行權；chown u:g：同時換擁有者與群組。
  • setfacl -m（modify）：設 ACL；-d -m（default）：新內容繼承。
組合 chmod 777 public; chmod 770 grp1; chmod 775 grp2（Q17）。
翻車：讀寫目錄通常還要 x；子目錄可進前，所有父目錄也要 x。chmod -R 可能把一般檔誤加執行權。
> / >> / 2> / 2>&1 / | / tee / xargs｜重導與管線
白話 > 把螢幕輸出存檔；| 把前一指令結果給下一指令；tee 同時顯示與存檔；xargs 把文字變參數。
  • >（redirect）：覆寫 stdout；>>（append）：追加 stdout。
  • 2>：stderr；2>&1：stderr 跟 stdout 到同一處。
  • tee -a（append）：顯示且追加存檔；xargs -0：安全處理含空白檔名。
組合 ls sample2 > log.txt 2>&1（Q18）；ps ... | xargs kill（Q26）。
翻車：2>&1 必須在 > log 後面；cat f > f 會把 f 清空（Q19）。

03
ps / top / pgrep / pidof / kill｜看與結束行程
白話 ps 是行程快照，top 是即時資源儀表板，pgrep/pidof 按名字找 PID，kill 是發結束訊號。
  • ps auxf：all/user/x/forest，完整行程＋樹狀父子關係。
  • top -b -n 1：batch/iterations，輸出一次、可接管線。
  • kill -TERM（15）：正常結束；kill -KILL（9）：強制、最後手段。
組合 top -b -n 1 | head -n 10 | tail -n 3：前三個高資源行程（Q20）。
翻車：先確認 PID/命令再 kill；-9 不讓程式清理檔案與連線。
timedatectl / chronyc / hwclock / crontab｜時間、NTP、排程
白話 timedatectl 是系統時鐘設定；chrony 是網路校時；hwclock 是硬體 RTC；cron 是定時鬧鐘。
  • set-timezone Asia/Taipei：改時區；set-ntp false：停自動校時。
  • chronyc sources -v：看校時來源；hwclock -w：系統→RTC。
  • crontab -e/-l：編輯／列使用者排程；tail -f：追 log。
組合 systemctl restart chronyd; chronyc sources -v：改來源後驗證。
翻車：使用者 crontab 無「使用者」欄，/etc/crontab 有；cron 請寫絕對路徑。
lsblk / blkid / mount / umount / xfs_growfs｜磁碟與掛載
白話 lsblk 看硬碟地圖，blkid 取 UUID，mount 把磁碟接到資料夾，fstab 讓開機自動掛載。
  • lsblk -f（filesystem）：看 FSTYPE、UUID、掛載點。
  • mount -a（all）：依 /etc/fstab 掛所有尚未掛載項。
  • xfs_growfs /掛載點：線上擴 XFS。
  • swapon --show：看啟用中的 swap 與 TYPE。
組合 blkid /dev/sdb → 編 fstab → mount -a → findmnt /data：設永久掛載並驗證。
翻車：mkfs 會清空裝置；XFS growfs 參數是掛載點、只能擴不能縮。
ip / nmcli / ping / ss / host / curl｜網路設定與診斷
白話 ip 看網卡/IP/路由，nmcli 設網路，ping 測連通，ss 看 port，host 查 DNS，curl 實測 HTTP。
  • ip -br a（brief/address）：短格式看 IP；ip route：看預設閘道。
  • ping -c 4（count）：只送四包；ss -tulpen：TCP/UDP/listen/PID。
  • host -t a（type）：查 A/TXT/CNAME；curl -I：只取 HTTP header。
組合 ip -br a → ip route → ping gateway → host 名稱 → curl -I URL：由網卡到服務逐層排錯。
翻車：nmcli 改完要 nmcli connection up <連線>；ping 通不表示 Web 服務通。
rpm / dnf｜查、裝、移除套件
白話 rpm 是已安裝套件資料庫；dnf 是能自動處理相依性的軟體商店。
  • rpm -q/-qi/-ql/-qf：查是否已裝／詳細／檔案清單／檔案屬於誰。
  • dnf install/remove：安裝／移除；dnf provides：查誰提供命令。
  • dnf repolist --all：含 disabled repo；-y：自動回答 yes。
組合 dnf list httpd → dnf install httpd → rpm -q httpd：查、裝、確認。
翻車：rpm -i 不會處理相依性；一般安裝用 dnf。移除時看清 dnf 的連帶移除清單。
systemctl / journalctl / firewall-cmd｜服務、日誌、防火牆
白話 systemctl 是服務總開關，journalctl 是黑盒子日誌，firewall-cmd 是主機門口規則。
  • start/stop/restart：立即控制服務；enable --now：開機自啟＋立即啟動。
  • journalctl -u svc -b -f：指定服務／本次開機／即時追蹤。
  • --permanent：永久規則；--reload：立即套用永久規則。
組合 systemctl status svc → journalctl -u svc -b → ss -tulpen：服務排錯流程。
翻車：start 不等於 enable；permanent 後不 reload，現在不生效。

套件與網路

Q1　查詢 httpd 套件用 sudo dnf list httpd，要如何安裝？

sudo dnf install httpd
若不想確認：sudo dnf install -y httpd。安裝後可用 rpm -q httpd 確認；需啟動服務才用 systemctl enable --now httpd。

Q2　如何移除 httpd 套件？

sudo dnf remove httpd
erase 與 remove 等價；確認連帶移除清單再按 y。

Q3　設定 IP 資訊，用 root 身份執行什麼指令？

sudo nmtui（文字介面）。或指令流程：
sudo nmcli connection modify ens160 ipv4.method manual ipv4.addresses 192.168.1.11/24 ipv4.gateway 192.168.1.1 ipv4.dns 168.95.1.1
sudo nmcli connection up ens160
重點：改完要重新啟用連線才生效。

Q4　在 Windows 要顯示「控制台\所有控制台項目\網路連線」，用什麼指令？

ncpa.cpl。按 Win+R 輸入；看 IP 詳細資訊用 ipconfig /all。

Q5　從 ip a 的結果看，ens160 和 ens192 哪張網卡對應到 NAT？

此題需看題目截圖，不能只憑網卡編號。流程：
  1. ip a 記下兩張網卡的 IP 網段與 MAC（link/ether）。
  2. 在 VMware 虛擬網路編輯器看 VMnet8（NAT）的子網路與 MAC。
  3. 網段或 MAC 對得上的就是 NAT；VMnet1 通常是 Host-only，橋接會與實體網路同網段。

檔案、帳號、權限、重導

Q6　儲存本地主機名稱的設定檔是什麼？要讓提示字元從 [student@localhost ~]$ 變成 [student@Server1 ~]$ 該改哪個檔？

設定檔：/etc/hostname。建議：sudo hostnamectl set-hostname Server1；或編輯 sudo vi /etc/hostname。登出再登入才會更新提示字元。

Q7　touch 除了更新現有檔案／目錄時間戳記，還有什麼功能？

檔案不存在時建立大小 0 的空檔。例：touch newfile；指定時間：touch -d "2026-01-01 08:00" newfile。

Q8　顯示檔案詳細屬性（大小、Inode、SELinux Context、時間戳記等），XXXXX /etc/passwd 的指令為何？

stat /etc/passwd

Q9　如何把 ls -X a/ 改成遞迴列出目錄與子目錄結構？

ls -R a/；保留 -X：ls -XR a/。

Q10　history 第 18 行是 mkdir -p a/b/c/d/e/f，如何快速再跑一次？

!18

Q11　把 sample1 內容的 : 改成 ,，同時直接寫入該檔案，如何修改 sed -e 's/:/,/g' sample1？

sed -i 's/:/,/g' sample1

Q12　如何修改 sed 指令，把 sample1 中包含 sync 的行刪除並寫入檔案？

sed -i '/sync/d' sample1

Q13　編輯腳本 /opt/hello 後，要能執行 sudo /opt/hello，需要如何修改檔案屬性？

sudo chmod +x /opt/hello，或 sudo chmod 755 /opt/hello。腳本第一行建議是 #!/bin/bash。

Q14　要顯示環境變數 PATH 的內容，如何修改指令 sudo echo？

echo $PATH；也可 printenv PATH。

Q15　大量建立使用者帳號與批次更新密碼的流程為何？

方法 A：sudo newusers users.txt（每行格式同 /etc/passwd：帳號:密碼:UID:GID:說明:家目錄:shell）。
方法 B：for u in s01 s02 s03; do sudo useradd "$u"; done，再 sudo chpasswd < pw.txt（每行：帳號:新密碼）。最後用 getent passwd 或 id 驗證。

Q16　執行 mkdir /class/{public,grp1,grp2} 出現 No such file or directory，如何修正？

sudo mkdir -p /class/{public,grp1,grp2}

Q17　如何修正 chmod xxx，使 public 為 drwxrwxrwx、grp1 為 drwxrwx---、grp2 為 drwxrwxr-x？

cd /class
sudo chmod 777 public
sudo chmod 770 grp1
sudo chmod 775 grp2
驗證：ls -ld public grp1 grp2

Q18　stderr(2) 轉到 stdout(1)，同時輸出到 log.txt，如何修改 ls sample2 > log.txt？

ls sample2 > log.txt 2>&1；或 ls sample2 &> log.txt。

Q19　執行 cat log.txt > log.txt 的結果為何？

log.txt 會變成空檔。因為 Shell 先處理 > log.txt，cat 開始讀之前檔案已被截斷。

Q20–Q30｜行程、時間、磁碟
05

行程與資源

Q20　top -b -n 1 | head -n 8 | tail -n 1 能找出最吃資源的 1 支程式，如何改成前 3 支？

top -b -n 1 | head -n 10 | tail -n 3
top 前 7 行是摘要與標題，第 8 行才是第一支程式；取到第 10 行再取最後 3 行。

Q21　要瞭解行程的上下層級（樹狀）關係，如何修改 sudo ps aux？

ps auxf；或 ps -ef --forest；或 pstree -p。

Q22　可用什麼指令找出程式的 PID？

pgrep httpd；pidof sshd；或 ps aux | grep httpd（會多抓到 grep 自己）。

Q25　行程 CPU 使用率為 53.5%，要篩出該 PID（1559），ps aux | awk '$3 >= XX {print $2}' 中的 XX 該怎麼設？

ps aux | awk '$3 >= 53 {print $2}'。第 3 欄是 %CPU、第 2 欄是 PID；53 或 53.5 都可，但門檻不可太低。

Q26　承上題，如何把篩出的 PID 直接結束（kill）？

kill $(ps aux | awk '$3 >= 53 {print $2}')
或：ps aux | awk '$3 >= 53 {print $2}' | xargs kill。一般 kill 是 SIGTERM(15)，無效才考慮 kill -9。

時間與排程

Q23　執行什麼指令停止服務，可將 timedatectl 中的 NTP service: active 變成 inactive？

sudo systemctl stop chronyd；或 sudo timedatectl set-ntp false。要開機也不啟動再加 systemctl disable chronyd。

Q24　如何修改 sudo timedatectl set-timezone，把時區改為台北時間？

sudo timedatectl set-timezone Asia/Taipei
確認：timedatectl。忘記名稱可用 timedatectl list-timezones | grep Taipei。

Q27　使用什麼指令把目前系統時間同步寫入硬體時鐘（RTC）？

sudo hwclock -w（system → hardware clock）。反向是 sudo hwclock -s。

Q28　即時動態監控 cron 排程日誌的指令？

sudo tail -f /var/log/cron；或 sudo journalctl -u crond -f。Ctrl+C 結束追蹤。

磁碟與檔案系統

Q29　卸載 /mydata/ 後，要測試 /etc/fstab 自動掛載設定是否正確，輸入什麼指令？

sudo umount /mydata
sudo mount -a
df -h /mydata 或 findmnt /mydata。重開機前一定先 mount -a。

Q30　如何把 XFS 檔案系統擴充到指定掛載點（例如 /mydata）？

sudo xfs_growfs /mydata
參數是掛載點，不是裝置；先擴底層空間，再 growfs，最後 df -h 確認。XFS 只能擴大，不能縮小。
