# 伺服器架設與規劃

整理自 [NTUB 伺服器架設與規劃 HackMD](https://hackmd.io/@ntub-class/B12EXeiufx)（115 學年度）。課程以 Enterprise Linux／Rocky Linux 為主，從作業系統、檔案、帳號權限延伸到網路、套件與服務管理，後半學期進入 Shell Script、DNS、Web、資料庫、NFS、Samba、SELinux、Container。

## 學習路線

Linux 與發行版 → 檔案與目錄 → 使用者與群組 → 權限 → 重導與管線 → 資源與行程 → 時間與排程 → 磁碟 → 網路 → 套件 → systemd 與日誌 →（期中考）→ Shell Script → DNS／Web／資料庫 → NFS／Samba → SELinux／Container →（期末上機考）

## 怎麼使用這個資料夾

本資料夾採用「**章節入口＋共用參考＋練習簿**」的混合結構：

- **依本頁的 11 章順序學習**，保留原課程脈絡。每章筆記都是「**口語版教學**」：先理解名詞 → 看最小指令 → 逐步操作 → 認識錯誤與安全風險，並整理出原課程頁面的完整內容。
- **查單一指令**：用 [[各章指令詳解]]，可直接搜尋參數、管線與組合範例。
- **動手練習**：用 [[原始課程練習]]（各章 LAB）。
- **考前複習**：用 [[期末練習與DNS補充]]（114 學年度期末練習 1、2 與 DNS）。
- **想知道現在進度、考試時間、環境設定**：看 [[00 課程介紹與進度]]。

這比把所有內容塞進單一長頁更適合 Obsidian；同時也比完全拆成數十個零散頁面更容易按照課程順序閱讀。

## 範例環境

教材以 Rocky Linux 8 類型的 Enterprise Linux 為示範（安裝說明與套件範例也有 Rocky 9），並驗證 RHEL 7／8／9、AlmaLinux 8／9、Rocky Linux 8／9 的指令大致相通。

- 示範主機：Server1 `192.168.1.11/24`、Server2 `192.168.1.12/24`，DNS `168.95.1.1`。
- 登入帳號：`student`（`wheel` 群組）與 `root`。
- 課堂（NTUB）使用 `172.16.X.31／32`、期末練習使用 `192.168.X.11／12` 或 `10.6.X.11／12`，X 為個人代號。

> [!warning] 原始範例的 IP、密碼與權限只適合課堂練習
> 實際部署時，應改用自己的網路規劃與安全設定，不要在真實環境重複使用示範密碼（如 `P@ssw0rd`、`exam`）。
