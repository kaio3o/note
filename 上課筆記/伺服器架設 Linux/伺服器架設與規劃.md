# 伺服器架設與規劃

整理自 [NTUB 伺服器架設與規劃 HackMD](https://hackmd.io/@ntub-class/B12EXeiufx)。課程以 Enterprise Linux／Rocky Linux 為主，從作業系統、檔案、帳號權限延伸到網路、套件與服務管理。

## 學習路線

Linux 與發行版 → 檔案與目錄 → 使用者與群組 → 權限 → 重導與管線 → 資源與行程 → 時間與排程 → 磁碟 → 網路 → 套件 → systemd 與日誌

## Obsidian 建議閱讀方式

本資料夾採用「章節入口＋共用參考＋練習簿」的混合結構：

- 先依本頁的 11 章順序學習，保留原課程的脈絡。
- 查單一指令時使用 [[各章指令詳解]]，可直接搜尋參數、管線與組合範例。
- 實作時使用 [[原始課程練習]]，其中保留原網頁 LAB 的步驟、來源連結與安全提醒。
- 原本的章節摘要與 [[檔案操作]] 保留，作為快速複習入口。

這比把所有內容塞進單一長頁更適合 Obsidian；同時也比完全拆成數十個零散頁面更容易按照課程順序閱讀。
