# 各章指令詳解

> [!abstract] 使用方式
> 這份筆記是「查指令」用；章節概念與學習順序請回到 [[伺服器架設與規劃]]。命令列中的 `<必要值>`、`[可選值]` 是語法佔位符，執行前請先確認目前使用者、路徑與目標檔案。

## 第一章：Linux 與發行版

### 查看系統與環境

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `uname` | `uname -a` | 顯示核心資訊；`-a` 顯示全部，`-r` 顯示核心版本，`-m` 顯示架構。 |
| `hostnamectl` | `hostnamectl status` | 查看主機名稱、作業系統與核心；`set-hostname <名稱>` 可修改主機名。 |
| `cat /etc/os-release` | — | 讀取發行版識別資訊，適合確認 Rocky/RHEL/AlmaLinux 版本。 |
| `man` | `man <command>` | 查詢指令手冊；搜尋用 `/<文字>`，離開按 `q`。 |
| `--help` | `command --help` | 快速查看參數，不一定涵蓋完整說明。 |

### 組合用法

```bash
uname -r && cat /etc/os-release
hostnamectl status | grep -E 'Operating System|Kernel|Static hostname'
```

`&&` 代表前一個指令成功才執行下一個；`|` 把前一個指令的輸出送給下一個指令。

## 第二章：檔案與目錄

### 路徑與目錄

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `pwd` | `pwd` | 顯示目前工作目錄。 |
| `ls` | `ls -lah <path>` | 列出檔案；`-l` 詳細欄位、`-a` 包含隱藏檔、`-h` 以易讀單位顯示。 |
| `cd` | `cd <path>` | 切換目錄；`cd ..` 上層、`cd -` 回上一個目錄、`cd ~` 家目錄。 |
| `tree` | `tree -L 2` | 顯示目錄樹；`-L` 限制深度。若未安裝可用 `find` 替代。 |
| `mkdir` | `mkdir -p a/b/c` | 建立目錄；`-p` 連同不存在的父目錄一起建立。 |

### 檔案操作

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `touch` | `touch file.txt` | 建立空檔或更新時間戳。 |
| `cp` | `cp -av source dest` | 複製；`-r` 遞迴目錄、`-a` 保留權限與時間、`-i` 覆寫前詢問、`-v` 顯示過程。 |
| `mv` | `mv -i old new` | 移動或重新命名；`-i` 避免意外覆寫。 |
| `rm` | `rm -ri <path>` | 刪除；`-r` 遞迴、`-i` 逐項確認。不要把 `-rf` 用在未確認的路徑。 |
| `file` | `file <path>` | 判斷檔案類型，不只依副檔名。 |
| `stat` | `stat <path>` | 查看大小、權限、inode、存取/修改時間。 |
| `ln` | `ln -s target link` | 建立連結；`-s` 符號連結，省略則是硬連結。 |

### 文字查看、過濾與搜尋

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `cat` | `cat -n file` | 輸出內容；`-n` 加行號。 |
| `less` | `less file` | 分頁查看；`/pattern` 搜尋、`n` 下一筆、`q` 離開。 |
| `head` / `tail` | `head -n 10 file` / `tail -f log` | 看前/後幾行；`-n` 指定行數，`tail -f` 持續追蹤新增內容。 |
| `grep` | `grep -rinE 'error|fail' /var/log` | 搜尋文字；`-i` 忽略大小寫、`-r` 遞迴、`-n` 顯示行號、`-v` 反向排除、`-E` 延伸正規表示式。 |
| `find` | `find /var/log -type f -name '*.log'` | 依條件找檔；`-type f/d` 檔案/目錄、`-name` 名稱、`-mtime` 修改天數、`-size` 大小。 |
| `sort` / `uniq` | `sort file | uniq -c` | 排序並統計重複行；`uniq` 通常要先排序。 |
| `wc` | `wc -lwm file` | 統計行、字、字元。 |
| `cut` | `cut -d: -f1 /etc/passwd` | 依分隔符取欄位；`-d` 分隔字元、`-f` 欄位。 |
| `awk` | `awk -F: '{print $1}' /etc/passwd` | 欄位處理；`-F` 指定分隔符。 |
| `sed` | `sed -n '1,5p' file` | 文字轉換；`-n` 關閉預設輸出，`s/old/new/g` 取代。 |

### 組合範例

```bash
find /var/log -type f -name '*.log' -print0 | xargs -0 grep -Hi 'error'
ps aux | grep '[s]shd'
cut -d: -f1 /etc/passwd | sort | uniq -c
find . -type f -name '*.conf' -exec grep -nH 'Listen' {} +
```

`xargs -0` 搭配 `-print0` 可降低檔名含空白或特殊字元時的解析問題；`grep '[s]shd'` 可避免把 grep 自己列入結果。

### vi/vim 最小操作表

- `i` 進入插入模式；`Esc` 回指令模式。
- `:w` 儲存、`:q` 離開、`:wq` 儲存離開、`:q!` 放棄修改。
- `dd` 刪除一行、`yy` 複製一行、`p` 貼上、`u` 復原。
- `/文字` 搜尋；`gg` 到檔案開頭、`G` 到結尾。

## 第三章：使用者與群組

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `id` | `id <user>` | 查看 UID、GID 與所屬群組。 |
| `whoami` | `whoami` | 顯示目前有效使用者。 |
| `who` / `w` | `w` | 查看登入者與目前工作。 |
| `useradd` | `useradd -m -s /bin/bash <user>` | 建立帳號；`-m` 建家目錄、`-s` 登入 shell、`-g` 主要群組、`-G` 附加群組。 |
| `passwd` | `passwd <user>` | 設定密碼；不要把密碼直接寫進公開腳本。 |
| `usermod` | `usermod -aG wheel <user>` | 修改帳號；`-aG` 追加附加群組，不能漏掉 `-a`。 |
| `userdel` | `userdel -r <user>` | 刪除帳號；`-r` 同時刪除家目錄，執行前應備份。 |
| `groupadd` | `groupadd <group>` | 建立群組；`-g` 指定 GID。 |
| `gpasswd` | `gpasswd -a <user> <group>` | 管理群組成員；`-a` 加入、`-d` 移除。 |
| `newgrp` | `newgrp <group>` | 在目前 shell 以指定群組為有效群組。 |
| `su` / `sudo` | `su - <user>` / `sudo <command>` | 切換使用者或以授權身分執行；`su -` 會載入目標使用者登入環境。 |
| `newusers` / `chpasswd` | `newusers userlist` / `chpasswd < newpass.txt` | 批次建立帳號或修改密碼；輸入檔含密碼，實驗後應妥善刪除。 |

相關檔案：`/etc/passwd`、`/etc/shadow`、`/etc/group`、`/etc/gshadow`。一般使用者可讀 passwd/group，但 shadow 應只讓 root 或受控程序讀取。

## 第四章：權限

### 權限欄位

`ls -l` 的 `-rwxr-x---` 依序是檔案類型、擁有者、群組、其他人。檔案的 `r=4,w=2,x=1`；目錄的 `x` 代表能進入/穿越，`r` 代表列出內容，`w` 代表新增刪除項目。

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `chmod` | `chmod 640 file` / `chmod u+x script.sh` | 修改權限；數字法或符號法，`-R` 遞迴但要小心。 |
| `chown` | `chown user:group file` | 修改擁有者與群組；`-R` 遞迴。 |
| `chgrp` | `chgrp group file` | 只修改群組。 |
| `umask` | `umask 027` | 設定新檔案預設扣除的權限。 |
| `getfacl` / `setfacl` | `setfacl -m u:alice:rw file` | 查看/設定 ACL；`-m` 修改、`-x` 移除、`-R` 遞迴。 |

### 組合範例

```bash
install -m 750 app.sh /usr/local/bin/app.sh
find /srv/share -type f -exec chmod 640 {} +
find /srv/share -type d -exec chmod 750 {} +
chown -R root:class /srv/share
```

## 第五章：重導與管線

| 語法 | 功能 |
|---|---|
| `command > file` | 將標準輸出覆寫到檔案。 |
| `command >> file` | 將標準輸出追加到檔案。 |
| `command 2> error.log` | 將標準錯誤輸出導向檔案。 |
| `command >out 2>err` | 分開保存輸出與錯誤。 |
| `command >all.log 2>&1` | 將標準輸出與錯誤合併保存。 |
| `command &> all.log` | Bash 常用的合併寫法。 |
| `command < input` | 從檔案提供標準輸入。 |
| `cmd1 | cmd2` | 把 cmd1 的標準輸出送給 cmd2。 |
| `tee` | `cmd | tee result.log | cmd2` 同時顯示、保存並傳遞輸出。 |

範例：

```bash
dnf repolist 2>&1 | tee dnf-check.log
journalctl -p warning..alert -b | tee warnings.log | less
grep -RIn 'timeout' /var/log 2>/dev/null | sort -t: -k1,1
```

## 第六章：資源與行程

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `ps` | `ps auxf` / `ps -ef` | 查看行程；`a/u/x` 顯示不同使用者、格式與無終端程序，`f` 樹狀；`-e` 全部、`-f` 詳細。 |
| `top` | `top` | 互動監看；`P` CPU、`M` 記憶體、`k` 結束行程、`q` 離開。 |
| `free` | `free -h` | 記憶體與 swap；`-h` 易讀。 |
| `uptime` | `uptime` | 查看運行時間、登入者與 load average。 |
| `lscpu` / `lsblk` | `lscpu` / `lsblk -f` | 查看 CPU、區塊裝置與檔案系統。 |
| `kill` | `kill -TERM <PID>` | 傳送訊號；先用 TERM，必要時才用 KILL。 |
| `pkill` / `killall` | `pkill -f 'pattern'` | 依名稱/命令列結束行程，範圍較大，執行前要核對。 |
| `nice` / `renice` | `nice -n 10 command` | 調整 CPU 排程優先權；數值越高通常越不優先。 |
| `vmstat` / `iostat` | `vmstat 1 5` | 取樣觀察 CPU、記憶體、I/O；iostat 可能需安裝 sysstat。 |

安全流程：先 `ps` 或 `top` 確認 PID，再用 `kill -TERM`，確認仍存在後才考慮 `kill -KILL`。不要直接使用未確認的 `kill -9`。

## 第七章：時間與排程

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `date` | `date '+%F %T %z'` | 顯示格式化時間；`%F` 日期、`%T` 時間、`%z` 時區。 |
| `timedatectl` | `timedatectl status` | 查看時間、時區、NTP；`set-timezone Asia/Taipei` 設定時區、`set-ntp true` 啟用校時。 |
| `chronyc` | `chronyc sources -v` | 查看 chrony 校時來源；`tracking` 查看同步狀態。 |
| `crontab` | `crontab -e` / `crontab -l` | 編輯/列出使用者排程；欄位為「分 時 日 月 星期」。 |
| `systemd timer` | `systemctl list-timers` | 查看 systemd 排程器，適合需要服務相依與 journal 的任務。 |

cron 範例：`0 2 * * * /usr/local/sbin/backup.sh >> /var/log/backup.log 2>&1` 代表每天 02:00 執行。腳本請使用絕對路徑、設定執行權限並記錄錯誤。

## 第八章：磁碟與檔案系統

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `df` | `df -hT` | 查看檔案系統剩餘空間與類型；`-T` 顯示類型。 |
| `du` | `du -sh /var/*` | 查看目錄用量；`-s` 總計、`-h` 易讀。 |
| `lsblk` | `lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS` | 盤點磁碟、分割區與掛載點。 |
| `blkid` | `blkid /dev/vdb1` | 查看 UUID 與檔案系統類型。 |
| `mount` / `umount` | `mount /dev/vdb1 /mnt/data` | 掛載/卸載；卸載前確認沒有程序使用目錄。 |
| `mkfs` | `mkfs.xfs /dev/vdb1` | 建立檔案系統；會破壞目標分割區資料，僅對已確認的裝置操作。 |
| `findmnt` | `findmnt /mnt/data` | 查詢掛載來源與選項。 |

永久掛載流程：先 `lsblk -f` 取得 UUID，再編輯 `/etc/fstab`，最後以 `mount -a` 驗證；不要直接重開機才發現 fstab 語法錯誤。

## 第九章：網路

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `ip` | `ip -br addr` / `ip route` | 查看介面、IP 與路由；`-br` 簡潔格式。 |
| `ping` | `ping -c 4 <host>` | 測試 ICMP；`-c` 限制次數。成功不代表應用服務可用。 |
| `ss` | `ss -tulpen` | 查看監聽與連線；`-t` TCP、`-u` UDP、`-l` listening、`-p` 程序、`-e` 詳細、`-n` 數字。 |
| `curl` | `curl -I https://example.com` | 測試 HTTP；`-I` 只取標頭、`-L` 跟隨轉址、`-v` 詳細、`-o` 輸出檔。 |
| `dig` | `dig +short example.com` | 查 DNS；`+short` 簡化輸出。 |
| `traceroute` | `traceroute <host>` | 觀察路由跳點，可能受防火牆或 ICMP 限制。 |
| `nmcli` | `nmcli device status` | NetworkManager 管理介面；`connection show` 查看連線設定。 |

診斷順序：`ip -br addr` → `ip route` → `ping -c 4 gateway` → `dig` → `curl -I` → `ss -tulpen`。這能區分介面、路由、DNS 與服務層問題。

## 第十章：RPM 與 dnf

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `rpm` | `rpm -qa` | 查詢已安裝套件；`-q` 查詢、`-a` 全部、`-qi` 詳細、`-ql` 檔案清單、`-qf <file>` 反查來源套件。 |
| `dnf search` | `dnf search <keyword>` | 搜尋可用套件。 |
| `dnf info` | `dnf info <package>` | 查看版本、來源與摘要。 |
| `dnf install` | `sudo dnf install <package>` | 安裝套件；`-y` 自動回答 yes，正式環境應先檢查 transaction。 |
| `dnf remove` | `sudo dnf remove <package>` | 移除套件，先確認相依套件。 |
| `dnf update` | `sudo dnf update` | 更新套件；可指定套件名稱。 |
| `dnf provides` | `dnf provides '*/named'` | 找出提供某檔案或命令的套件。 |
| `dnf history` | `dnf history info <ID>` | 查看或稽核套件交易紀錄。 |

常見流程：`dnf search` → `dnf info` → `dnf install` → `rpm -q` → `systemctl status`。不要把 `rpm -i` 當成 dnf 的替代品；rpm 不會自動解決相依性。

## 第十一章：systemd 與日誌

| 指令 | 常用寫法 | 功能與參數 |
|---|---|---|
| `systemctl status` | `systemctl status sshd` | 查看服務目前狀態與最近訊息。 |
| `systemctl start/stop/restart` | `sudo systemctl restart sshd` | 啟動、停止、重啟服務。 |
| `systemctl enable` | `sudo systemctl enable --now sshd` | 設定開機啟動；`--now` 同時立即啟動。 |
| `systemctl disable` | `sudo systemctl disable --now service` | 取消開機啟動並停止。 |
| `systemctl is-active/is-enabled` | — | 適合腳本中取得服務狀態。 |
| `systemctl list-units` | `systemctl list-units --type=service --state=failed` | 列出載入中的服務或失敗服務。 |
| `journalctl` | `journalctl -u sshd -b -n 100` | 查看 journal；`-u` 指定服務、`-b` 本次開機、`-n` 最近 N 行、`-f` 即時追蹤、`-p` 依優先級篩選、`--since/--until` 依時間篩選。 |
| `systemd-analyze` | `systemd-analyze blame` | 分析開機耗時；`critical-chain` 查看關鍵相依鏈。 |

故障排查：

```bash
systemctl status nginx --no-pager
journalctl -u nginx -b -p warning..alert --no-pager
ss -lntp | grep ':80'
```

先看服務狀態，再看本次開機的 journal，最後確認服務是否真的監聽目標埠號。
