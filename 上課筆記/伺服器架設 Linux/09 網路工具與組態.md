# 網路工具與組態

## 常用診斷

```bash
ip addr
ip route
ss -tulpen
ping -c 4 8.8.8.8
curl -I https://example.com
dig example.com
hostnamectl
```

## 排查順序

1. `ip addr`：確認介面與 IP。
2. `ip route`：確認預設閘道。
3. `ping`：測試連線。
4. `dig`：確認 DNS。
5. `ss`：確認服務監聽的 IP 與 Port。
6. 檢查防火牆與服務狀態。
