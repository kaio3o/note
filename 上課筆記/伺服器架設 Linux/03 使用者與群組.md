## 一、先搞懂：Linux 怎麼認人？

Linux 其實**不是用名字認人，是用數字**：

- 使用者 → **UID**（User ID）
- 群組 → **GID**（Group ID）

名字只是方便人類閱讀。權限（見 [[04 檔案與目錄權限]]）判斷時，是看「這個檔案的擁有者 UID／群組 GID 跟你是不是一樣」。

| UID | 意義 |
|---|---|
| 0 | `root`，最高權限 |
| 1–999 | 系統帳號（給服務用，例如 `nginx`、`chrony`），通常不能登入 |
| 1000 以上 | 一般使用者 |

（範圍定義在 `/etc/login.defs` 的 `UID_MIN`／`UID_MAX`，Rocky 預設一般使用者從 1000 開始。）

> [!tip] 為什麼群組重要？
> 管理 100 個人，一個一個設權限很崩潰。把人放進群組，**對群組設一次權限**就好。公司比喻：每個員工有「主要部門」，但專案需要跨部門時，會另外建「專案小組」，這就是**主要群組 vs 次要群組**。

## 二、帳號與群組相關檔案

這些檔案是系統的「帳號資料庫」，**屬於敏感檔案**，所以資安稽核（帳號清查）時一定會檢查它們。

### 1. `/etc/passwd`：帳號基本資料

由 6 個 `:` 分成 **7 個欄位**。範例：

```text
student:x:1000:1000:Student User:/home/student:/bin/bash
 ①     ② ③   ④    ⑤            ⑥             ⑦
```

| # | 欄位 | 說明 |
|---|---|---|
| ① | 登入帳號 | 登入時輸入的名稱，**全系統不可重複** |
| ② | 密碼 | 現在固定寫 `x`，表示密碼放在 `/etc/shadow` |
| ③ | UID | 使用者編號，**全系統不可重複** |
| ④ | 主要群組 GID | 對應到 `/etc/group` 裡的定義 |
| ⑤ | 說明（GECOS） | 全名、暱稱等，可以空白 |
| ⑥ | 家目錄 | 預設放在 `/home/帳號` |
| ⑦ | 登入 Shell | 預設 `/bin/bash`；系統帳號常是 `/sbin/nologin`（不能登入） |

> [!tip] `/sbin/nologin` 是什麼？
> 給服務專用的帳號。有人嘗試登入它，會直接被擋下。這是「服務要有自己的帳號，但不准人拿來登入」的資安設計。

### 2. `/etc/shadow`：密碼與期限

為什麼要拆出來？因為 `/etc/passwd` 所有人都能讀（很多程式要查 UID 對應的名字），但密碼雜湊絕不能讓大家看，所以放在**只有 root 能讀**的 `shadow`。

由 8 個 `:` 分成 **9 個欄位**：

| # | 說明 |
|---|---|
| 1 | 帳號（對應 passwd 第 1 欄） |
| 2 | 密碼雜湊（SHA-512 加密後的結果；`!` 或 `*` 開頭表示被鎖定或沒設密碼） |
| 3 | 上次修改密碼的日期（從 1970-01-01 起算的**天數**） |
| 4 | 修改後幾天內**不能**再改（最小天數） |
| 5 | 幾天後**一定要**改（最大天數） |
| 6 | 到期前幾天開始警告 |
| 7 | 到期後經過幾天才停用帳號（寬限期） |
| 8 | 帳號失效日期（同樣從 1970-01-01 起算） |
| 9 | 保留欄位，未來用 |

### 3. `/etc/group`：群組與成員

共 **4 個欄位**：

```text
developers:x:1002:alice,bob
    ①      ② ③     ④
```

| # | 欄位 | 說明 |
|---|---|---|
| ① | 群組名稱 | |
| ② | 群組密碼 | 現在幾乎不用 |
| ③ | GID | 群組編號 |
| ④ | 成員 | 以逗號分隔 |

> [!note] 怎麼知道一個帳號的主要群組名稱？
> `/etc/passwd` 第 4 欄是 GID，到 `/etc/group` 第 3 欄查就知道名稱了。（`id 帳號` 一行就能看到。）
> 另外，`/etc/group` 第 4 欄通常只列「次要群組成員」，主要群組的成員不會列在裡面。

還有 `/etc/gshadow`（群組密碼檔，一般不用管）。

### 4. 開帳號時參照的設定

| 檔案 | 作用 |
|---|---|
| `/etc/login.defs` | 開帳號的**預設規則** |
| `/etc/skel/` | 新帳號家目錄的**範本**，裡面的檔案會被複製到每個新家目錄 |

`/etc/login.defs` 常見參數：

| 參數 | 用途 |
|---|---|
| `MAIL_DIR` | 帳號的 mail 檔案放哪裡 |
| `PASS_MAX_DAYS` | 密碼最長有效天數 |
| `PASS_MIN_DAYS` | 密碼最短使用天數（改完後多久內不能再改） |
| `PASS_WARN_AGE` | 到期前幾天警告 |
| `UID_MIN`／`UID_MAX` | 一般帳號可用的 UID 範圍 |
| `GID_MIN`／`GID_MAX` | 一般群組可用的 GID 範圍 |
| `ENCRYPT_METHOD` | 密碼雜湊演算法 |

`/etc/skel/` 的妙用：你可以把「公司使用條款」、預設 `.bashrc`、環境變數設定放進去，之後新開的每一個帳號都會自動拿到。

> [!warning] 別直接用 vi 編輯這些檔案
> 它們雖然是文字檔，但格式一個冒號錯了，可能整個系統登入不了。**要用 `useradd`、`usermod`、`groupadd` 這些指令改**。真的要手動改，用 `vipw`／`vigr`（會幫你加鎖並檢查）。

## 三、帳號管理

> 本節大多需要 root。切換身分：`sudo su -`（細節見第五節）。

### 1. `id`：查看帳號資訊

```bash
id root
# uid=0(root) gid=0(root) groups=0(root)
```

- `uid=0(root)`：UID 是 0，名字是 root
- `gid=0(root)`：**主要群組**
- `groups=...`：所有群組（含主要與次要）

**一個帳號只能有一個主要群組，但能有多個次要群組。**

類似指令：`whoami`（我是誰）、`who`／`w`（誰登入了）、`getent passwd 帳號`（從系統資料庫查，包含 LDAP 等來源）。

### 2. `useradd`：建立帳號

流程：確認不存在 → 建立 → 確認結果。

```bash
id user1                # id: 'user1': no such user  → 還沒有
useradd user1
id user1                # uid=1000(user1) gid=1000(user1) groups=1000(user1)
ls -l /home             # drwx------. 2 user1 user1 62 ... user1
```

什麼參數都不加時，Rocky／RHEL 系會：

- 自動建一個**同名群組**當主要群組（所以 gid=1000(user1)）。
- 自動建立**家目錄** `/home/user1`，權限 `drwx------`（只有本人能進）。

常用參數：

| 參數 | 作用 | 範例 |
|---|---|---|
| `-m` | 強制建立家目錄（RHEL 預設就會建，Debian/Ubuntu 的 `useradd` 預設不會） | |
| `-s` | 指定登入 shell | `-s /bin/bash`、`-s /sbin/nologin` |
| `-g` | 指定**主要**群組 | `-g developers` |
| `-G` | 指定**次要**群組（多個用逗號） | `-G wheel,it` |
| `-u` | 指定 UID | `-u 1101` |
| `-d` | 指定家目錄路徑 | `-d /data/alice` |
| `-c` | 說明（GECOS） | `-c "Alice Wang"` |

```bash
useradd -m -s /bin/bash -g developers -G wheel alice
```

### 3. `passwd`：設定密碼

新帳號**沒有密碼就不能登入**（shadow 第 2 欄是 `!!`），必須設定。

```bash
passwd root      # 改 root 自己
passwd user1     # root 幫 user1 改
```

規則：

| | 一般使用者 | root |
|---|---|---|
| 能改誰的密碼 | 只能改自己的 | 自己和所有人的 |
| 密碼不符合原則時 | **失敗** | **仍可成功**（只會警告 `BAD PASSWORD`） |

輸入密碼時**螢幕不會顯示任何字元**（連星號都沒有），這是正常的，不是當機。

常用：`passwd -l 帳號`（鎖定）、`passwd -u`（解鎖）、`passwd -e`（強制下次登入改密碼）、`echo 'user:密碼' | chpasswd`（非互動）。

### 4. `usermod`：修改帳號

| 情境 | 指令 |
|---|---|
| 員工留職停薪 → 鎖定 | `usermod -L user1` |
| 員工回來 → 解鎖 | `usermod -U user1` |
| 調職到人力資源部（改**主要**群組） | `usermod -g hr user1` |
| 追加次要群組（不影響原本的） | `usermod -aG wheel user1` |
| 改登入 shell | `usermod -s /sbin/nologin user1` |
| 改帳號名稱 | `usermod -l 新名 舊名` |

```bash
usermod -g hr user1
id user1       # uid=1000(user1) gid=1002(hr) groups=1002(hr)
```

> [!danger] `-aG` 的 `-a` 絕對不能漏
> `usermod -G wheel user1`（沒 `-a`）會把 user1 **原本所有次要群組都覆蓋掉**，只剩 wheel。追加一律用 `-aG`。
> 上面調職範例需要先 `groupadd hr`。

### 5. `chage`：密碼有效期限

定期換密碼可降低帳號被破解後長期被濫用的風險。

```bash
chage -l user1        # 列出 user1 的密碼政策（用 -l 看清單比較清楚）
chage -M 90 user1     # 密碼最長 90 天要改（Maximum）
chage -m 2 user1      # 改完後至少 2 天才能再改（minimum）
chage -W 7 user1      # 到期前 7 天警告（Warning）
chage -d 0 user1      # 強制下次登入時一定要改密碼
chage -E 2026-12-31 user1   # 帳號 2026-12-31 失效
```

> [!note] 原文 `chage user1` 的小補充
> 原教材寫 `chage user1` 列出政策；多數版本需要加 `-l` 才是「列出」，不加會進入互動模式逐項詢問。要看就用 `chage -l`。

### 6. `userdel`：刪除帳號

```bash
userdel user1       # 刪帳號，家目錄預設保留
userdel -r user1    # 連家目錄、mail 一起刪
```

帳號有生命週期：新增 → 修改 → 停用 → 刪除。**定期清掉不需要的帳號**能減少被利用的機會（離職員工的帳號是經典資安漏洞）。刪之前記得備份資料、確認這個帳號沒有正在跑的行程（`ps -u user1`）。

## 四、群組管理

### `groupadd`：新增群組

```bash
groupadd grp1
grep grp1 /etc/group     # grp1:x:1003:
groupadd grp2
```

已存在的群組會報錯忽略。`-g 2000` 可指定 GID。

### `groupdel`：刪除群組

有三個規則：

1. **主要群組不能刪**：只要有任何帳號把它當主要群組，就刪不掉。
2. 若是某些帳號的**次要群組**，刪掉後那些帳號會自動被移出。
3. 如果檔案原本屬於這個群組，刪除後 `ls -l` 的群組欄會變成**數字 GID**（因為找不到名字了）。

```bash
useradd -g grp2 user2     # user2 的主要群組是 grp2
groupdel grp2             # ❌ 失敗：不能刪除某帳號的主要群組

userdel -r user2          # 先把 user2 刪掉
groupdel grp2             # ✅ 成功

groupdel grp1             # ✅ 沒人把 grp1 當主要群組，可以刪
```

### `gpasswd`：管理群組成員

完整生命週期範例：建 `staff` → 加入成員 → 檢查 → 移除成員 → 刪群組。

```bash
groupadd staff
gpasswd -a user1 staff     # -a add：加入
gpasswd -a user2 staff
id user1                   # groups 裡會多一個 staff
id user2
gpasswd -d user1 staff     # -d delete：移出
gpasswd -d user2 staff
groupdel staff
```

另外兩個好用的：`gpasswd -M user1,user2 staff`（直接設定整個成員名單）、`newgrp 群組`（臨時把某個群組當有效群組）。

> [!tip] 為什麼剛加進群組，`id` 沒變／權限沒生效？
> 群組資訊是**登入時**載入的。被加進群組的人要**登出再登入**，或用 `newgrp 群組名` 開一個新 shell 才會生效。

## 五、切換特權帳號：`su` 與 `sudo`

管理員日常操作原則：**平常用一般帳號，需要時才提權。** 有兩種方式：

### `su`（Substitute User）

切換成另一個使用者；沒指定就是 root。需要輸入**目標帳號**的密碼。

```bash
su -            # 變成 root，並載入完整登入環境
su - alice      # 變成 alice
su alice        # 沒有減號：只換身分，環境變數（PATH、家目錄等）還是原本的
```

`su -` 的 `-` 代表模擬完整登入（載入對方的環境變數、切到對方家目錄）。沒加 `-` 常會遇到「指令找不到」之類怪問題，因為 PATH 還是舊的。

### `sudo`（Superuser Do）

以其他人（預設 root）的身分**只執行這一個指令**，輸入的是**自己的密碼**。

```bash
whoami           # student
sudo whoami      # root
sudo su -        # 先用 sudo 提權，再切成 root 完整環境（課程常用）
sudo -l          # 看看我能用 sudo 做什麼
```

在 Enterprise Linux 上，一般使用者**不是想用 sudo 就能用**，要被加進 **`wheel` 群組**：

```bash
usermod -aG wheel student
```

細緻權限由 `/etc/sudoers`（用 `visudo` 編輯）控制。

### 兩者運作差異

| | `su` | `sudo` |
|---|---|---|
| 需要的密碼 | 目標帳號的 | 自己的 |
| 運作方式 | 開一個**新 shell**，以目標身分運行，直到 `exit` | 暫時提權執行**單一指令**，結束就回到原本權限 |
| 稽核 | 較難追蹤你在 root shell 裡做了什麼 | 每次 sudo 都會記錄到日誌（誰、什麼時候、做什麼） |
| 建議 | 偶爾用 | **日常優先用** |

## 六、批次建立帳號（LAB）

- `newusers`：從檔案批次**建立**帳號。
- `chpasswd`：從檔案批次**修改密碼**（原教材標題寫 `chpass`，實際指令是 `chpasswd`）。

`newusers` 輸入檔的格式與 `/etc/passwd` 很像，但第 2 欄放**明文密碼**：

```text
帳號:密碼:UID:GID:說明:家目錄:登入Shell
stu001:P@ssw0rd:1101:1001::/home/stu001:/bin/bash
```

### 流程總覽

```bash
mkdir lab1; cd lab1
vi userlist                       # 寫入帳號清單（見上）
id stu001                         # 先確認不存在 → no such user
grep stu00 /etc/passwd            # 也沒有
newusers < userlist               # 批次建立（< 是輸入重導，見第五章）
grep stu00 /etc/passwd            # 確認建好了
grep stu00 /etc/shadow            # 密碼雜湊也有了
su - stu001                       # 用新密碼登入測試
```

批次改密碼：

```bash
vi newpass.txt                    # 格式：帳號:新密碼
chpasswd < newpass.txt            # 等同 cat newpass.txt | chpasswd
```

移除：

```bash
userdel stu001                    # 家目錄還在
rm -rf /home/stu001               # 要自己清
userdel -r stu002                 # 一次連家目錄刪掉
```

> [!warning] 資安提醒
> - 檔案裡是**明文密碼**，用完要刪（`shred -u newpass.txt`），並且設 `chmod 600`。
> - 課程用的 `P@ssw0rd` 只是示範，真實環境請用隨機密碼，並設定 `chage -d 0` 讓使用者第一次登入就改。
> - `newusers` 的 GID（這裡是 1001）必須是**已存在**的群組，否則群組欄位要自己先建好。

完整的指令版筆記與安全改寫在 [[原始課程練習]]。

## 七、練習：用戶與群組（NTUB 練習）

目標：建 3 個群組、3 個帳號，再把某些人加入次要群組。

```bash
sudo su -
groupadd class
groupadd it
groupadd acc

useradd -g class alex      # 主要群組都是 class
useradd -g class bob
useradd -g class judy

gpasswd -a bob it          # bob、alex 加入 it
gpasswd -a alex it
gpasswd -a judy acc        # judy、alex 加入 acc
gpasswd -a alex acc
```

預期結果：

| 帳號 | 主要群組 | 次要群組 |
|---|---|---|
| alex | class | it, acc |
| bob | class | it |
| judy | class | acc |

驗證：`id alex`、`id bob`、`id judy`、`getent group it`。

## 八、補充：沒有 Linux 主機？用 WSL

**WSL（Windows Subsystem for Linux）** 讓 Windows 直接跑 Linux 環境，很適合在自己電腦練前面幾章（檔案、帳號、權限、管線）。

### 需求

- Windows 10 家用版 1903（組建 18362）以上，或 Windows 11。
- 要先在「控制台 → 程式與功能 → 開啟或關閉 Windows 功能」打開 **Windows Subsystem for Linux** 與 **虛擬機器平台**，並**重開機**。
- 學校教室電腦如果有還原卡／防寫，沒開這些功能就不用試了。

### 安裝（PowerShell，建議以系統管理員開啟）

```powershell
wsl --list --online        # 或 wsl -l -o，看有哪些發行版可裝
wsl --update               # 先更新 WSL
wsl --install -d Ubuntu    # 安裝 Ubuntu（也可指定 Ubuntu-22.04）
wsl --list --verbose       # 或 wsl -l -v，看已安裝的與狀態 (Running / Stopped)
```

第一次啟動會要你建立 Linux 使用者與密碼。

> [!note] WSL 預設是 Ubuntu，不是 Rocky
> 指令大多通用，但**套件管理是 `apt` 不是 `dnf`**（第十章要注意）。想練 Rocky 可以另外用 VM 或匯入 Rocky 的 WSL 映像。

### 常見問題

| 問題 | 解法 |
|---|---|
| **忘記 WSL 密碼** | PowerShell 執行 `wsl -d Ubuntu-22.04 --user root` 進去，再用 `passwd 使用者` 重設 |
| 啟動時出現「處理結束，代碼為 4294967295 (0xffffffff)」，狀態是 Stopped | 重新執行 `wsl --install -d Ubuntu` 後用 `wsl -l -v` 確認變 Running；或把 Windows Terminal 設定檔的啟動命令加上 `~`，例如 `"C:\Windows\system32\wsl.exe" ~ -d Ubuntu-20.04` |
| 錯誤 `Wsl/Service/0x80040326` | 用系統管理員 PowerShell：`wsl --update`，然後 `wsl --shutdown`，再重新 `wsl -d 發行版` |
| `code .` 打不開 VS Code | `wsl --shutdown` 後重開 wsl |
| WSL 看不到網站（想從外部連進來） | 在 Windows 管理員 CMD／PowerShell 加連接埠轉送：`netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=80 connectaddress=<WSL的IP> connectport=80` |

### 在 WSL 裡存取 Windows 的檔案

Windows 的磁碟會掛在 `/mnt/` 底下：

```bash
cd /mnt/d       # D 槽
ls -l
df              # 看磁碟使用狀況
curl ifconfig.me   # 查詢對外 IP
```

這四個指令：`df` 看磁碟空間、`cd /mnt/d` 切到 D 槽、`ls -l` 詳細清單、`curl ifconfig.me` 取得自己的公網 IP。
