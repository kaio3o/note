# 使用者與群組

- 使用者有 UID；群組有 GID。
- `/etc/passwd` 儲存帳號基本資訊；`/etc/shadow` 儲存密碼雜湊與到期資訊；`/etc/group` 儲存群組成員。
- `root` 擁有最高權限，日常操作應使用一般帳號，必要時才提升權限。

```bash
id username
whoami
useradd username
passwd username
usermod -aG wheel username
userdel username
groupadd groupname
groupdel groupname
su - username
sudo command
```

`usermod -aG` 的 `-a` 很重要，避免覆蓋既有附加群組。

## 從零開始理解

Linux 不只用「帳號名稱」辨識使用者，實際上使用 UID；群組也有 GID。檔案權限會根據「檔案擁有者、檔案群組、其他人」判斷，因此群組是多人共享權限的工具。

### 主要群組與附加群組

一個使用者通常有一個主要群組，也可以加入多個附加群組：

```bash
sudo groupadd developers
sudo useradd -m -s /bin/bash -g developers alice
sudo passwd alice
sudo usermod -aG wheel alice
id alice
```

- `-m`：建立家目錄。
- `-s /bin/bash`：指定登入後使用的 shell。
- `-g developers`：設定主要群組。
- `-aG wheel`：把 wheel 追加到附加群組；`-a` 不可漏掉。

### 為什麼看不到剛加入的群組？

群組資訊通常在登入時載入。使用者加入新群組後，可能要登出再登入，或使用：

```bash
newgrp developers
id
```

### root、sudo、su 的差異

- `root`：最高權限帳號。
- `sudo command`：只讓一個命令暫時以管理權限執行。
- `su - user`：切換成另一個使用者，`-` 代表載入完整登入環境。

初學時優先使用 `sudo`，因為命令範圍較小，也較容易追蹤誰做了什麼。

> [!warning] 不要直接修改帳號資料檔
> `/etc/passwd`、`/etc/shadow`、`/etc/group` 是系統資料庫格式。新增或修改帳號應使用 `useradd`、`usermod`、`groupadd` 等工具，避免手動改壞格式。
