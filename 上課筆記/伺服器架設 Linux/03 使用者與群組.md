# 使用者與群組

- 使用者有 UID；群組有 GID。
- `/etc/passwd` 儲存帳號基本資訊；`/etc/shadow` 儲存密碼雜湊與到期資訊；`/etc/group` 儲存群組成員。
- `root` 擁有最高權限，日常操作應使用一般帳號，必要時才提升權限。

```bash
id username
whoami
useradd username
passwd username
usermod -aG wheel username
userdel username
groupadd groupname
groupdel groupname
su - username
sudo command
```

`usermod -aG` 的 `-a` 很重要，避免覆蓋既有附加群組。
