# Linux 與發行版

> [!abstract] 一句話版本
> **Linux = 核心（kernel）**，**發行版 = 核心 + 工具 + 軟體打包好的完整系統**。我們說「裝 Linux」，其實是在「挑一個發行版來裝」。

原始章節：[Linux 與發行版](https://hackmd.io/@ntub-class/B12EXeiufx/%2F_QeF6gMSRVmiagdO3gbFMw)、[Linux 應用範圍與選擇](https://hackmd.io/@ntub-class/B12EXeiufx/%2FcM-CztSeTf-_OLKsIIvWrg)、[Enterprise Linux 9 安裝流程](https://hackmd.io/@ntub-class/B12EXeiufx/%2F5NN9Rh0KTFioCe4p8MM8Ug)

## 一、Linux 到底是什麼？

很多人會把 Linux 當成「某間公司賣的產品」，這是誤會。要拆成兩個東西看：

| | 是什麼 | 誰做的 |
|---|---|---|
| **核心（Kernel）** | 作業系統最底層的部分，專門管 CPU、記憶體、硬碟、網卡這些硬體 | Linus Torvalds 1991 年開始開發，現在由全球志願者與公司共同維護，原始碼在 [kernel.org](https://www.kernel.org) 人人可下載 |
| **發行版（Distribution）** | 把核心 + 系統函式庫 + 工具程式 + 應用軟體打包成可安裝的完整產品 | Red Hat、Canonical（Ubuntu）、Rocky 基金會等 |

### 用「橋樑」理解核心

應用程式（例如瀏覽器）**不會**直接去碰硬碟。它會呼叫「系統函式」跟核心說：「我要讀這個檔案。」核心去硬碟拿資料，再交給應用程式。

```text
應用程式  →  系統函式庫  →  核心 (Kernel)  →  硬體（硬碟、記憶體、網卡）
```

所以核心就像一座橋，連接「軟體」與「硬體」。但光有核心還不能用——你需要指令（`ls`、`cp`）、函式庫、套件管理器，這些加在一起才是「完整作業系統」。

## 二、Linux 的五大特色

| 特色 | 白話說明 |
|---|---|
| **開放原始碼** | 採 GPL 授權，任何人都能自由使用、複製、散佈、修改。這也是整個資訊產業能圍繞 Linux 長大的原因。 |
| **多用途、跨平台** | 桌機、筆電、伺服器、嵌入式裝置，連你手上的 Android 手機都是 Linux 核心。 |
| **安全性高** | 攻擊面小、權限機制嚴謹、可高度設定；社群發現漏洞後修補速度快。 |
| **低成本** | 不用付授權費，舊硬體也跑得動，適合預算有限的單位。 |
| **社群活躍** | 全球志願者持續改進，遇到問題常能在論壇找到答案。 |

大公司（Google、Amazon、IBM、Intel、Oracle 等）都大量使用 Linux；資料中心、雲端、網路伺服器、超級電腦幾乎都是它的地盤。

## 三、什麼是發行版？

發行版通常由三塊組成：

1. **核心**：提供基本功能與硬體管理。
2. **系統工具**：設定工具、軟體更新工具、網路設定工具、系統監控工具等。
3. **應用程式**：瀏覽器、辦公軟體、多媒體播放器……（桌面版的賣點）。

### GPL：發行版的「遊戲規則」

GPL 的精神是：

- 原始碼要能自由散佈、使用。
- 你拿原始碼改出來的新東西，**也必須用 GPL 公開**。

所以所有 Linux 發行版都得公開原始碼，任何人都能拿來改、打包出自己的發行版。這就是為什麼發行版這麼多：

- **CloudLinux**：由 CentOS 改出來，專門做虛擬主機／Web 主機。
- **Manjaro**：由 Arch Linux 改出來，好上手、套件管理強，適合桌面與開發。
- **OpenWrt**：跑在路由器等嵌入式裝置上。
- **Fedora Scientific**：針對科學計算與資料分析。

### 發行版之間最大的差異

差在**預設裝了哪些套件**，以及**系統設定與管理工具**。舉例：

| | Red Hat Enterprise Linux（RHEL） | Ubuntu |
|---|---|---|
| 定位 | 企業、伺服器 | 桌面、好上手 |
| 取向 | 重**穩定與安全**，預設套件較精簡 | 重**使用者體驗**，內建應用較多 |
| 特色 | 嚴格的安全套用與作業流程 | 容易上手 |

## 四、Linux 能拿來做什麼？

老師提醒：與其問「Linux 能做什麼？」，不如問「**我要拿 Linux 做什麼？**」

- ✅ 學作業系統、程式開發、網路、IoT：Linux 是很好的起點。
- ❌ 想玩 3A 遊戲：可跑的遊戲有限，Windows 比較合適。

實際應用已經遍地開花：

- 終端使用者：Android 手機、網路交換器、IP 分享器（路由器）、飛機上的娛樂系統。
- 雲端：Amazon AWS、Google GCP 的底層都大量使用 Linux。

## 五、怎麼選發行版？

網路上常有人吵「哪個最好用」，老師認為**這題沒必要爭**，因為：

1. **初學**：易用性最重要，先搞懂 Linux 特性，再去比較各家。
2. **企業**：要穩定、安全 → 選企業版發行版（有嚴格的流程與安全設定，讓管理員能謹慎操作）。
3. **核心／驅動開發**：選開發工具與套件齊全的發行版。

> [!tip] 每個優點都可能是另一個需求的缺點
> 沒有絕對好壞，只有「適不適合你的情境」。

企業導入資訊技術通常看三件事：

- 版本**通用性高**。
- 能做成**標準作業程序（SOP）**。
- 相關**解決方案與支援容易取得**。

### 為什麼這門課選 Rocky Linux？

- Rocky Linux 是用 **RHEL 的原始碼重新編譯**而來，等於「免費版 RHEL」。
- 創辦人也是當年 CentOS 的主導者，CentOS 老用戶很容易轉過來。
- 學會它，**RHEL、AlmaLinux、Oracle Linux** 的指令基本上通用。

| 發行版 | 簡介 |
|---|---|
| RHEL | Red Hat 的商業企業版，付費買支援 |
| Rocky Linux | RHEL 的社群重編版，免費，課程使用 |
| AlmaLinux | 另一個 RHEL 重編版，也免費 |
| Oracle Linux | Oracle 的 RHEL 相容版 |

> [!note] 8 或 9 都行
> 課程文件中安裝示範是 Rocky 8，選擇說明寫 Rocky 9。兩者管理概念相同，指令幾乎一樣，你裝哪個都可以。

## 六、Enterprise Linux 安裝流程（Rocky Linux，VM 版）

### 準備

- 虛擬化工具：VMware Workstation Player（原文寫 Station Player）。老師有放下載教學影片。
- 先下載好 ISO（來源見 [[00 課程介紹與進度]]）。ISO 是「安裝光碟」，不是已安裝好的系統。

### 步驟（照螢幕畫面走）

| # | 畫面 | 要做什麼 |
|---|---|---|
| 1 | 開機選單 | 用鍵盤上下鍵選 **Install Rocky Linux 8**（Enter） |
| 2 | 選擇語系 | 挑你習慣的語言（英文介面比較好查資料） |
| 3 | **Time & Date** | 設定時間與時區（台灣選 Asia/Taipei），按 **Done** |
| 4 | **Software Selection** | 選 **Minimal Install**（最小安裝，只裝必要的，攻擊面小），按 **Done** |
| 5 | **Installation Destination** | 勾選要裝的磁碟，選 **Automatic**（自動分割），按 **Done** |
| 6 | **Root Password** | 設定 root 密碼，按 **Done** |
| 7 | 回主畫面 | 確認無誤按 **Begin Installation** |
| 8 | 安裝中 | 等它跑完 |
| 9 | 完成 | 按 **Reboot System** 重開機 |

> [!tip] 為什麼選 Minimal Install？
> 伺服器的原則是「**用不到的就不要裝**」：裝越少，要維護、要更新、可能被攻擊的東西就越少。缺什麼之後再用 `dnf install` 補。
>
> 另外，課程環境有個 `student` 帳號（屬於 `wheel` 群組）。若安裝時沒建，裝完可以自己用 `useradd` 建（見 [[03 使用者與群組]]）。

> [!warning] 沒看過的步驟
> 原文的畫面截圖我只有文字描述；實際介面細節（按鈕位置）請以你的版本為準。如果要啟用網路，記得在 **Network & Host Name** 把網卡切到 ON。

## 七、安裝完第一件事：確認「我在哪、我是誰、這是什麼系統」

```bash
whoami              # 我是誰
pwd                 # 我在哪個目錄
hostnamectl         # 主機名稱與系統概況
cat /etc/os-release # 發行版名稱與版本
uname -r            # 核心版本
```

| 指令 | 回答的問題 |
|---|---|
| `whoami` | 目前登入的帳號 |
| `pwd` | 目前所在目錄 |
| `hostnamectl` | 主機名稱、作業系統、核心 |
| `/etc/os-release` | 這是 Rocky、Alma 還是 RHEL？幾版？ |
| `uname -r` | 正在跑哪個核心版本 |

### 安裝前檢查清單

1. 確認 CPU、記憶體、磁碟與網路需求。
2. 從官方或可信任鏡像下載 ISO，並核對校驗碼（checksum）。
3. 規劃主機名稱、IP、DNS、磁碟分割與管理帳號。
4. 安裝後更新套件，並檢查時間、網路與權限。

## 八、初學者常見迷思

- ❌ 「Linux、Ubuntu、Rocky 是同一個東西」→ Linux 是核心；Ubuntu、Rocky 是發行版。
- ❌ 不知道自己是誰就下管理指令 → 先 `whoami`，要管理權限再加 `sudo`。
- ❌ 沒確認版本就照抄教學 → 不同發行版套件名稱、設定工具、預設服務都可能不同。
- ❌ 把 ISO 當成已裝好的系統 → ISO 是安裝媒體，裝完才是硬碟裡的系統。

> [!tip] 小練習
> 只跑第七節的五個指令，把輸出裡的「發行版、版本、核心、主機名稱、目前使用者」各寫成一句話。
