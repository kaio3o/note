```python
你要爬一個 n 階的樓梯。每次你都可以選擇爬 1 階或 2 階。請問你有多少種不同的方法可以爬到樓頂？

dp[n] = dp[(n-1)] + dp[(n-2)]

# 如果n == 1 就直接回傳1
if n == 1:
	return 1
# 先設定第一階與第二階的答案
a, b = 1, 2

# 從3 開始到n 階
for i in range(3, n+1):
	# 每次算a 跟b 
	# a 為到達前兩階的方法數
	# b 為前到達一階的方法數
	a, b = b, a+b
	
return b

```
