```python
你要爬一個 n 階的樓梯。每次你都可以選擇爬 1 階或 2 階。請問你有多少種不同的方法可以爬到樓頂？

dp[n] = dp[(n-1)] + dp[(n-2)]

# 如果n == 1 就直接回傳1
if n == 1:
	return 1
# 先設定第一階與第二階的答案
a, b = 1, 2

# 從3 開始到n 階
for i in range(3, n+1):
	# 每次算a 跟b 
	# a 為到達前兩階的方法數
	# b 為前到達一階的方法數
	a, b = b, a+b
	
return b

```

### 746.
```python
現在每一階樓梯都有一個成本（Cost）。
- 你可以從第 0 階或第 1 階出發（這兩階不用付費）。
- 只要你離開某一階往上跳（跳 1 階或 2 階），你就必須支付該階的成本。
- 你的目標是走到「樓頂」（注意：頂層是第 n 階，超越最後一個有成本的階梯）。
  
cost = [10, 15, 20]

n = len(cost)

# 到達每階的成本表 到最後一個再多一個
dp = [0] * (n+1)

# 去跑
for i in range(2, n+1):
	dp[i] = min(dp[i-1]+ cost[i-1], dp[i-2] + cost[i-2])
	
return dp[n]
```
