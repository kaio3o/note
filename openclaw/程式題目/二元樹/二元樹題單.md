## 常用解題模板

### DFS 遞迴模板

```python
def dfs(root):
    if not root:
        return base_value

    left = dfs(root.left)
    right = dfs(root.right)

    return combine(root.val, left, right)
```

### BFS 層序遍歷模板

```python
from collections import deque

def level_order(root):
    if not root:
        return []

    q = deque([root])
    result = []

    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)

            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)

        result.append(level)

    return result
```

### BST 範圍限制模板

```python
def is_valid_bst(root):
    def dfs(node, low, high):
        if not node:
            return True
        if not (low < node.val < high):
            return False
        return dfs(node.left, low, node.val) and dfs(node.right, node.val, high)

    return dfs(root, float('-inf'), float('inf'))
```

## 重點觀念

- **二元樹題目通常先想遞迴定義**：目前節點需要從左右子樹拿到什麼資訊？
- **前序** 常用於「先處理自己」或序列化。
- **中序** 在 BST 中會得到遞增序列。
- **後序** 常用於「子樹資訊回傳給父節點」，例如深度、最大路徑、樹形 DP。
- **BFS** 適合層序、最短距離、每層統計。
- **BST 題目一定要利用範圍限制或中序遞增特性**。
