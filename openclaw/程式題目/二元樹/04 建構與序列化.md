# 04 建構與序列化

這類題目會要求你根據遍歷結果重建樹，或把樹轉成字串再還原。

## 必練題目

### 1. Construct Binary Tree from Preorder and Inorder Traversal
> 說明：根據前序的根節點順序與中序的左右子樹分界，重建原本的二元樹。

- 難度：Medium
- 核心：
  - preorder 第一個元素是 root
  - inorder 可以切出左子樹與右子樹

```python
def build_tree(preorder, inorder):
    index = {v: i for i, v in enumerate(inorder)}
    pre_i = 0

    def helper(left, right):
        nonlocal pre_i
        if left > right:
            return None

        root_val = preorder[pre_i]
        pre_i += 1
        root = TreeNode(root_val)

        mid = index[root_val]
        root.left = helper(left, mid - 1)
        root.right = helper(mid + 1, right)
        return root

    return helper(0, len(inorder) - 1)
```

### 2. Construct Binary Tree from Inorder and Postorder Traversal
> 說明：根據後序最後一個值是根節點，以及中序切分左右子樹的位置，重建原本的二元樹。

- 難度：Medium
- 核心：
  - postorder 最後一個元素是 root
  - 先建右子樹，再建左子樹

```python
def build_tree(inorder, postorder):
    index = {v: i for i, v in enumerate(inorder)}
    post_i = len(postorder) - 1

    def helper(left, right):
        nonlocal post_i
        if left > right:
            return None

        root_val = postorder[post_i]
        post_i -= 1
        root = TreeNode(root_val)

        mid = index[root_val]
        root.right = helper(mid + 1, right)
        root.left = helper(left, mid - 1)
        return root

    return helper(0, len(inorder) - 1)
```

### 3. Serialize and Deserialize Binary Tree（二元樹序列化與反序列化）
> 說明：把二元樹轉成字串保存，之後再依照同樣規則還原成原本的樹結構。

- 難度：Hard
- 核心：用前序 DFS 搭配 `#` 表示空節點

```python
class Codec:
    def serialize(self, root):
        vals = []

        def dfs(node):
            if not node:
                vals.append('#')
                return
            vals.append(str(node.val))
            dfs(node.left)
            dfs(node.right)

        dfs(root)
        return ','.join(vals)

    def deserialize(self, data):
        vals = iter(data.split(','))

        def dfs():
            val = next(vals)
            if val == '#':
                return None
            node = TreeNode(int(val))
            node.left = dfs()
            node.right = dfs()
            return node

        return dfs()
```

### 4. Flatten Binary Tree to Linked List（二元樹展平成 linked list）
> 說明：把二元樹原地展開成只使用右指標串起來的 linked list，順序要符合前序遍歷。

- 難度：Medium
- 核心：展開順序要符合前序遍歷

```python
def flatten(root):
    prev = None

    def dfs(node):
        nonlocal prev
        if not node:
            return
        dfs(node.right)
        dfs(node.left)
        node.right = prev
        node.left = None
        prev = node

    dfs(root)
```

## 小結

建樹題核心在於：

- 找到 root。
- 用另一個遍歷序列切出左右子樹。
- 注意遞迴順序是否會影響 index 移動。
