# 01 基礎遍歷與結構判斷

這一組題目用來熟悉二元樹最核心的操作：**遍歷、深度、比較、翻轉、對稱**。

## 必練題目

### 1. Binary Tree Preorder Traversal（前序遍歷）
d526

- 難度：Easy
- 核心：Root → Left → Right
- 練習重點：遞迴、stack 迭代

```python
def preorder(root):
    if not root:
        return []
    return [root.val] + preorder(root.left) + preorder(root.right)
```

---

### 2. Binary Tree Inorder Traversal（中序遍歷）

- 難度：Easy
- 核心：Left → Root → Right
- 練習重點：BST 的中序會是排序後結果

```python
def inorder(root):
    if not root:
        return []
    return inorder(root.left) + [root.val] + inorder(root.right)
```

---

### 3. Binary Tree Postorder Traversal（後序遍歷）

- 難度：Easy
- 核心：Left → Right → Root
- 練習重點：很多樹形 DP 都用後序

```python
def postorder(root):
    if not root:
        return []
    return postorder(root.left) + postorder(root.right) + [root.val]
```

### 4. Binary Tree Level Order Traversal（層序遍歷）

- 難度：Medium
- 核心：BFS queue
- 練習重點：一層一層處理節點

```python
from collections import deque

def level_order(root):
    if not root:
        return []

    q = deque([root])
    ans = []

    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        ans.append(level)

    return ans
```

### 5. Maximum Depth of Binary Tree（二元樹最大深度）

- 難度：Easy
- 核心：目前節點深度 = 左右子樹最大深度 + 1

```python
def max_depth(root):
    if not root:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))
```

### 6. Same Tree（相同的樹）

- 難度：Easy
- 核心：兩棵樹目前節點相同，左右子樹也都相同

```python
def is_same_tree(p, q):
    if not p and not q:
        return True
    if not p or not q:
        return False
    return (
        p.val == q.val
        and is_same_tree(p.left, q.left)
        and is_same_tree(p.right, q.right)
    )
```

### 7. Symmetric Tree（對稱二元樹）

- 難度：Easy
- 核心：左子樹與右子樹互為鏡像

```python
def is_symmetric(root):
    def mirror(a, b):
        if not a and not b:
            return True
        if not a or not b:
            return False
        return a.val == b.val and mirror(a.left, b.right) and mirror(a.right, b.left)

    return mirror(root.left, root.right) if root else True
```

---

### 8. Invert Binary Tree（翻轉二元樹）

- 難度：Easy
- 核心：交換每個節點的左右子樹

```python
def invert_tree(root):
    if not root:
        return None
    root.left, root.right = invert_tree(root.right), invert_tree(root.left)
    return root
```
