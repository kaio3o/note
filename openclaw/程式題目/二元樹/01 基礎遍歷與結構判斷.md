### 1. Binary Tree Preorder Traversal（前序遍歷）
> 說明：先處理目前節點，再依序走左子樹與右子樹，常用來複製樹或輸出根優先的結構。
> d526.py
> d526_01.py

- 難度：Easy
- 核心：Root → Left → Right
- 練習重點：遞迴、stack 迭代

```python
def preorder(root):
    if not root:
        return []
    return [root.val] + preorder(root.left) + preorder(root.right)
```

---

### 2. Binary Tree Inorder Traversal（中序遍歷）
> 說明：先走左子樹，再處理目前節點，最後走右子樹；在 BST 中會得到由小到大的順序。
> d526_02.py

- 難度：Easy
- 核心：Left → Root → Right
- 練習重點：BST 的中序會是排序後結果

```python
def inorder(root):
    if not root:
        return []
    return inorder(root.left) + [root.val] + inorder(root.right)
```

---

### 3. Binary Tree Postorder Traversal（後序遍歷）
> 說明：先處理左右子樹，最後才處理目前節點，適合需要先知道子問題答案的遞迴題。
> d526_03.py

- 難度：Easy
- 核心：Left → Right → Root
- 練習重點：很多樹形 DP 都用後序

```python
def postorder(root):
    if not root:
        return []
    return postorder(root.left) + postorder(root.right) + [root.val]
```

### 4. Binary Tree Level Order Traversal（層序遍歷）
> 說明：一層一層由上到下、由左到右拜訪節點，通常使用 BFS queue 來維護下一批節點。
> d562_04.py
- 難度：Medium
- 核心：BFS queue
- 練習重點：一層一層處理節點

```python
from collections import deque

def level_order(root):
    if not root:
        return []

    q = deque([root])
    ans = []

    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        ans.append(level)

    return ans
```

### 5. Maximum Depth of Binary Tree（二元樹最大深度）
> 說明：計算從根節點走到最深葉節點需要經過幾層，也就是樹的最大高度。
> d526_05.py

- 難度：Easy
- 核心：目前節點深度 = 左右子樹最大深度 + 1

```python
def max_depth(root):
    if not root:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))
```

### 6. Same Tree（相同的樹）
> 說明：判斷兩棵樹的結構與每個對應節點的值是否完全一樣。
> d526_06.py

- 難度：Easy
- 核心：兩棵樹目前節點相同，左右子樹也都相同

```python
def is_same_tree(p, q):
    if not p and not q:
        return True
    if not p or not q:
        return False
    return (
        p.val == q.val
        and is_same_tree(p.left, q.left)
        and is_same_tree(p.right, q.right)
    )
```

### 7. Symmetric Tree（對稱二元樹）
> 說明：判斷一棵樹的左半部與右半部是否互為鏡像。

- 難度：Easy
- 核心：左子樹與右子樹互為鏡像

```python
def is_symmetric(root):
    def mirror(a, b):
        if not a and not b:
            return True
        if not a or not b:
            return False
        return a.val == b.val and mirror(a.left, b.right) and mirror(a.right, b.left)

    return mirror(root.left, root.right) if root else True
```

### 8. Invert Binary Tree（翻轉二元樹）
> 說明：把每個節點的左子樹與右子樹交換，讓整棵樹左右鏡射。

- 難度：Easy
- 核心：交換每個節點的左右子樹

```python
def invert_tree(root):
    if not root:
        return None
    root.left, root.right = invert_tree(root.right), invert_tree(root.left)
    return root
```
