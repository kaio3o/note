# 05 進階遞迴與樹形 DP

進階二元樹題目通常不是單純遍歷，而是要在每個節點計算「選或不選」、「往上能貢獻什麼」、「目前子樹最好的答案」。

## 必練題目

### 1. Binary Tree Maximum Path Sum（二元樹最大路徑和）

- 難度：Hard
- 核心：
  - 回傳給父節點：只能選一條往上的路徑
  - 更新答案：可以同時取左 + root + 右

```python
def max_path_sum(root):
    ans = float('-inf')

    def gain(node):
        nonlocal ans
        if not node:
            return 0

        left = max(gain(node.left), 0)
        right = max(gain(node.right), 0)

        ans = max(ans, node.val + left + right)
        return node.val + max(left, right)

    gain(root)
    return ans
```

### 2. House Robber III（打家劫舍 III）

- 難度：Medium
- 核心：每個節點有兩種狀態：
  - rob：偷目前節點，不能偷左右 child
  - skip：不偷目前節點，左右 child 可偷可不偷

```python
def rob(root):
    def dfs(node):
        if not node:
            return (0, 0)

        left_rob, left_skip = dfs(node.left)
        right_rob, right_skip = dfs(node.right)

        rob_this = node.val + left_skip + right_skip
        skip_this = max(left_rob, left_skip) + max(right_rob, right_skip)
        return rob_this, skip_this

    return max(dfs(root))
```

### 3. Binary Tree Cameras（二元樹監控）

- 難度：Hard
- 核心：節點狀態
  - 0：未被監控
  - 1：有攝影機
  - 2：已被監控但沒有攝影機

```python
def min_camera_cover(root):
    cameras = 0

    def dfs(node):
        nonlocal cameras
        if not node:
            return 2

        left = dfs(node.left)
        right = dfs(node.right)

        if left == 0 or right == 0:
            cameras += 1
            return 1
        if left == 1 or right == 1:
            return 2
        return 0

    if dfs(root) == 0:
        cameras += 1
    return cameras
```

### 4. Recover Binary Search Tree（恢復 BST）

- 難度：Medium
- 核心：BST 中序應該是遞增；找到兩個順序錯誤的節點並交換

```python
def recover_tree(root):
    first = second = prev = None

    def inorder(node):
        nonlocal first, second, prev
        if not node:
            return
        inorder(node.left)

        if prev and prev.val > node.val:
            if not first:
                first = prev
            second = node
        prev = node

        inorder(node.right)

    inorder(root)
    first.val, second.val = second.val, first.val
```

### 5. Vertical Order Traversal of a Binary Tree（二元樹垂直遍歷）

- 難度：Hard
- 核心：記錄每個節點的 row、col，再排序

```python
from collections import defaultdict

def vertical_traversal(root):
    nodes = []

    def dfs(node, row, col):
        if not node:
            return
        nodes.append((col, row, node.val))
        dfs(node.left, row + 1, col - 1)
        dfs(node.right, row + 1, col + 1)

    dfs(root, 0, 0)
    nodes.sort()

    ans = []
    prev_col = None
    for col, row, val in nodes:
        if col != prev_col:
            ans.append([])
            prev_col = col
        ans[-1].append(val)

    return ans
```

## 小結

樹形 DP 的思考方式：

1. 目前節點有哪些狀態？
2. 每個狀態需要從左右子樹拿什麼？
3. 回傳給父節點的資訊，和全域答案是否不同？
4. 空節點的狀態應該怎麼定義最方便？
