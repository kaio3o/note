# 02 路徑與深度問題

這類題目通常會問：從根節點到葉節點、任意節點到任意節點、或某個子樹的高度與路徑資訊。

## 必練題目

### 1. Minimum Depth of Binary Tree（二元樹最小深度）
> 說明：找出從根節點到最近葉節點的最短層數，重點是不能把不存在的子樹當成有效路徑。

- 難度：Easy
- 核心：注意「只有一邊子樹」時不能直接取 0

```python
def min_depth(root):
    if not root:
        return 0
    if not root.left:
        return 1 + min_depth(root.right)
    if not root.right:
        return 1 + min_depth(root.left)
    return 1 + min(min_depth(root.left), min_depth(root.right))
```

---

### 2. Balanced Binary Tree（平衡二元樹）
> 說明：判斷每個節點的左右子樹高度差是否都不超過 1。

- 難度：Easy
- 核心：每個節點的左右子樹高度差不能超過 1
- 技巧：用 `-1` 表示已經不平衡，提早返回

```python
def is_balanced(root):
    def height(node):
        if not node:
            return 0
        left = height(node.left)
        if left == -1:
            return -1
        right = height(node.right)
        if right == -1:
            return -1
        if abs(left - right) > 1:
            return -1
        return 1 + max(left, right)

    return height(root) != -1
```

### 3. Diameter of Binary Tree（二元樹直徑）
> 說明：找出樹中任意兩個節點之間最長的路徑長度，路徑不一定要經過根節點。

- 難度：Easy
- 核心：經過某節點的最長路徑 = 左高度 + 右高度

```python
def diameter_of_binary_tree(root):
    ans = 0

    def depth(node):
        nonlocal ans
        if not node:
            return 0
        left = depth(node.left)
        right = depth(node.right)
        ans = max(ans, left + right)
        return 1 + max(left, right)

    depth(root)
    return ans
```

### 4. Path Sum（路徑總和）
> 說明：判斷是否存在一條從根節點到葉節點的路徑，其節點值總和等於目標值。

- 難度：Easy
- 核心：從根到葉節點的路徑和是否等於 target

```python
def has_path_sum(root, target):
    if not root:
        return False
    if not root.left and not root.right:
        return root.val == target
    return has_path_sum(root.left, target - root.val) or has_path_sum(root.right, target - root.val)
```

---

### 5. Binary Tree Paths（二元樹所有路徑）
> 說明：列出所有從根節點走到葉節點的完整路徑。

- 難度：Easy
- 核心：列出所有 root-to-leaf path

```python
def binary_tree_paths(root):
    ans = []

    def dfs(node, path):
        if not node:
            return
        path.append(str(node.val))
        if not node.left and not node.right:
            ans.append('->'.join(path))
        else:
            dfs(node.left, path)
            dfs(node.right, path)
        path.pop()

    dfs(root, [])
    return ans
```

### 6. Sum of Left Leaves（左葉子總和）
> 說明：加總所有「是父節點左孩子」且本身沒有子節點的葉節點值。

- 難度：Easy
- 核心：判斷某節點是否是父節點的左葉子

```python
def sum_of_left_leaves(root):
    if not root:
        return 0

    total = 0
    if root.left and not root.left.left and not root.left.right:
        total += root.left.val

    return total + sum_of_left_leaves(root.left) + sum_of_left_leaves(root.right)
```

---

### 7. Path Sum II（路徑總和 II）
> 說明：找出所有從根節點到葉節點、節點值總和等於目標值的路徑。

- 難度：Medium
- 核心：回傳所有符合 target 的 root-to-leaf path

```python
def path_sum(root, target):
    ans = []

    def dfs(node, remain, path):
        if not node:
            return
        path.append(node.val)
        remain -= node.val

        if not node.left and not node.right and remain == 0:
            ans.append(path[:])

        dfs(node.left, remain, path)
        dfs(node.right, remain, path)
        path.pop()

    dfs(root, target, [])
    return ans
```

## 小結

路徑題常見技巧：

- 用參數往下帶目前累積值。
- 用回傳值往上交回子樹資訊。
- 如果要求「任意節點到任意節點」，通常需要全域答案或 `nonlocal`。
