## 建議學習順序

### 第一階段：基礎解題能力

- Big-O 複雜度分析
- 陣列與字串操作
- 基礎排序
- Binary Search
- Two Pointers
- Sliding Window
- Prefix Sum
- Stack / Queue
- Recursion / Backtracking

目標：能穩定解 Easy 到入門 Medium。

### 第二階段：核心演算法能力

- Hash Map / Set
- Tree Traversal
- Heap / Priority Queue
- BFS / DFS
- Union Find
- Topological Sort
- 基礎 DP
- Knapsack / LIS / LCS

目標：能處理大多數 Medium 題。

### 第三階段：進階與競程題型

- Dijkstra / MST / SCC
- Segment Tree / Fenwick Tree
- Monotonic Stack / Queue
- Bitmask / Bitmask DP
- Sweep Line
- String Algorithms
- Computational Geometry

目標：能挑戰 Hard 題與競程題。

## 練習方法

每個主題建議照這個流程練：

1. 先理解使用場景：這個技巧通常用來解什麼問題？
2. 寫出暴力解：確認題意與邊界條件。
3. 找瓶頸：時間複雜度卡在哪裡？
4. 套用資料結構或演算法優化。
5. 記錄錯題：整理題型、關鍵轉折、容易錯的地方。
6. 重刷：隔幾天重新寫一次，不看答案。
