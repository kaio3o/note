# 圖論與搜尋

## 學習目標

能把問題轉換成圖模型，理解節點、邊、權重與方向，並選擇合適的圖演算法處理連通性、最短路、依賴順序與生成樹問題。

---

## 需要知道的觀念

### 1. 圖的基本概念

- **Vertex / Node**：節點。
- **Edge**：邊，表示關係或可移動路徑。
- **Directed Graph**：有向圖。
- **Undirected Graph**：無向圖。
- **Weighted Graph**：加權圖。
- **Unweighted Graph**：無權圖。
- **DAG**：Directed Acyclic Graph，有向無環圖。
- **Tree**：無環連通圖，是圖的一種特殊形式。

### 2. 圖的表示法

- **Adjacency List**：最常用，適合稀疏圖。
- **Adjacency Matrix**：適合節點少、查邊很頻繁。
- **Edge List**：適合 Kruskal、Bellman-Ford。

### 3. 圖搜尋

- **DFS**：找連通區塊、偵測環、拓撲排序、SCC。
- **BFS**：無權圖最短路、層序擴展、多源 BFS。
- **Bidirectional BFS**：起點與終點同時搜尋，縮小搜尋空間。

### 4. 常見圖論演算法

- **Topological Sort**：處理依賴關係與 DAG 排序。
- **Union Find / DSU**：快速合併集合、查連通性。
- **Dijkstra**：非負權重單源最短路。
- **Bellman-Ford**：可處理負權邊，偵測負環。
- **Floyd-Warshall**：所有點對最短路。
- **Kruskal / Prim**：最小生成樹 MST。
- **Tarjan / Kosaraju**：強連通分量 SCC。

## 練習方向

### 如何判斷用什麼

- 問「最少步數」且每步成本相同：BFS。
- 問「是否連通」：DFS / BFS / Union Find。
- 問「依賴順序」：Topological Sort。
- 問「非負權重最短路」：Dijkstra。
- 問「把所有點連起來成本最小」：MST。
- 問「有向圖互相可達群組」：SCC。

### 建模練習

每題先問：

1. 什麼是節點？
2. 什麼是邊？
3. 邊是否有方向？
4. 邊是否有權重？
5. 要求的是連通、最短路、排序、還是分組？
