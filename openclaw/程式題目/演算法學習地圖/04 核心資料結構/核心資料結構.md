# 核心資料結構

## 學習目標

理解各資料結構的特性、操作複雜度與適用場景，能根據題目需求選擇合適結構，而不是只背 API。

---

## 需要知道的觀念

### 1. Array / List

- 隨機存取 O(1)。
- 中間插入 / 刪除通常 O(n)。
- 常搭配排序、雙指針、滑動視窗、Prefix Sum。

### 2. Linked List

- 插入 / 刪除節點方便。
- 查找需要 O(n)。
- 常見技巧：快慢指針、反轉 linked list、dummy node。

### 3. Stack

- LIFO，後進先出。
- 適合括號匹配、DFS、單調棧、表達式解析。

### 4. Queue / Deque

- Queue：FIFO，常用於 BFS。
- Deque：兩端都能操作，常用於滑動視窗最大值、單調隊列。

### 5. Hash Map / Hash Set

- 平均 O(1) 查找、插入、刪除。
- 適合計數、去重、映射關係、快速查找。
- 注意 hash collision 與 key 的設計。

### 6. Heap / Priority Queue

- 快速取得最小值或最大值。
- Push / Pop 通常 O(log n)。
- 常用於 Top K、合併 K 個排序串列、Dijkstra、排程問題。

### 7. Tree

- Binary Tree：前序、中序、後序、層序遍歷。
- Binary Search Tree：左小右大，查找平均 O(log n)。
- Trie：前綴樹，適合字串前綴查詢、自動補全。
- Segment Tree：區間查詢與更新。
- Fenwick Tree：Prefix Sum 型動態查詢。

### 8. Union Find / DSU

- 支援 Find 與 Union。
- 搭配 path compression 與 union by rank/size。
- 適合連通性、群組合併、MST Kruskal。

## 練習方向

### 選資料結構的思路

- 需要快速查找：Hash Map / Set。
- 需要維護最大 / 最小：Heap。
- 需要先進先出：Queue。
- 需要後進先出：Stack。
- 需要區間查詢：Prefix Sum / Fenwick Tree / Segment Tree。
- 需要前綴字串查詢：Trie。
- 需要連通性合併：Union Find。

### 重要練習點

- 每種結構都要熟悉：新增、刪除、查找、遍歷。
- 記下操作複雜度。
- 練習用資料結構降低複雜度。
- 比較不同結構的取捨。
