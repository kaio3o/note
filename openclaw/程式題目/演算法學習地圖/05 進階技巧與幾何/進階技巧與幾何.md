# 進階技巧與幾何

## 學習目標

在基礎演算法、資料結構、DP 與圖論穩定後，學習更進階的解題技巧與計算幾何觀念，處理 Hard 題與競程題型。

---

## 需要知道的觀念

## 一、進階技巧

### 1. Bit Manipulation

- AND / OR / XOR / NOT / Shift。
- 判斷奇偶、取 bit、設 bit、清 bit。
- **lowbit**：常見於 Fenwick Tree。
- 子集合枚舉。
- Bitmask DP。

### 2. Monotonic Stack / Queue

- 維護單調遞增或遞減。
- 常用於下一個更大 / 更小元素。
- Monotonic Queue 可維護滑動視窗最大 / 最小值。

### 3. Binary Search on Answer

- 當答案具有單調性時，不直接求答案，而是二分猜答案。
- 搭配 `check(x)` 判斷某答案是否可行。

### 4. Sweep Line

- 把區間或幾何事件轉成「時間點 / 座標點事件」。
- 依序掃描事件，維護目前狀態。
- 適合區間重疊、會議室、矩形覆蓋。

### 5. Meet in the Middle

- 當 n 約 30～40，完整暴力 2^n 太大。
- 拆成左右兩半，各自枚舉，再合併。

### 6. String Algorithms

- **KMP**：字串匹配。
- **Rabin-Karp**：Rolling Hash。
- **Z Algorithm**：前綴匹配資訊。
- **Manacher**：最長回文子字串。

### 7. Advanced Range Query

- **Sparse Table**：靜態區間查詢，常用 RMQ。
- **Segment Tree Lazy Propagation**：區間更新 + 區間查詢。
- **Fenwick Tree**：動態 prefix sum。

## 二、計算幾何 Computational Geometry

### 1. 幾何基本元素

- Point
- Vector
- Line
- Segment
- Polygon
- Circle

### 2. 向量運算

- **Dot Product 內積**
  - 判斷角度、投影。
- **Cross Product 外積**
  - 判斷方向。
  - 計算平行四邊形面積。
  - 判斷線段相交。

### 3. 方向與相交

- 三點方向：clockwise / counterclockwise / collinear。
- 線段是否相交。
- 點是否在線段上。

### 4. 多邊形

- Shoelace Formula 計算多邊形面積。
- 判斷點是否在多邊形內。

### 5. 凸包 Convex Hull

- Graham Scan。
- Monotonic Chain。
- 找出包住所有點的最小凸多邊形。

### 6. 進階幾何問題

- 最近點對 Closest Pair of Points。
- 旋轉卡尺 Rotating Calipers。
- Voronoi Diagram。
- Delaunay Triangulation。

## 練習方向

### 進階技巧

- 先練使用場景，不要硬背。
- 每個技巧至少做 3～5 題同類型。
- 做完後整理「觸發關鍵字」。

常見觸發：

- 下一個更大 / 更小：Monotonic Stack。
- 滑動視窗最大值：Monotonic Queue。
- 答案最小化最大值：Binary Search on Answer。
- 區間重疊：Sweep Line。
- n 約 30～40 的 subset：Meet in the Middle。
- 大量區間查詢：Segment Tree / Fenwick Tree / Sparse Table。

### 幾何

- 先熟外積。
- 練習所有座標都用整數時避免浮點誤差。
- 熟悉 epsilon 比較。
- 先從方向判斷、線段相交、多邊形面積開始。
