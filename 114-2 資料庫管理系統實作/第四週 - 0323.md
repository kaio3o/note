- make a new directory for our code called `company` and navigate into it
- create a new virtual environment called `.venv` and activate it
- install Django and Black
- create a new Django project called `django_project`
- create a new app called `pages`
```
company/
├── manage.py                # Django 專案管理工具
├── django_project/          # 主專案設定資料夾 (Project Root)
│   ├── __init__.py
│   ├── asgi.py
│   ├── settings.py          # 核心設定 (需在此註冊 pages)
│   ├── urls.py              # 主路由 (在此 include pages.urls)
│   └── wsgi.py
└── pages/                   # 你的 App 資料夾 (Application)
    ├── __init__.py
    |-- templates
     |-- pages
     └── home.html           # 理想放在pages 資料夾內
    ├── admin.py             # 後台管理設定
    ├── apps.py
    ├── migrations/          # 資料庫遷移紀錄
    │   └── __init__.py
    ├── models.py            # 資料模型定義
    ├── tests.py             # 測試腳本
    ├── urls.py              # App 路由 (自己建立)
    ├── views.py             # 視圖函數 (邏輯處理)
    └── templates/           # 模板資料夾
        └── pages/           # 建議多一層 App 名稱的子目錄
            └── home.html
```

| **代碼**  | **說明**            | **範例輸出**             |
| ------- | ----------------- | -------------------- |
| **`Y`** | 四位數年份             | `2026`               |
| **`y`** | 兩位數年份             | `26`                 |
| **`m`** | 月份（補零 01-12）      | `03`                 |
| **`n`** | 月份（不補零 1-12）      | `3`                  |
| **`F`** | 完整月份名稱            | `March`              |
| **`M`** | 三個字母的月份簡寫         | `Mar`                |
| **`d`** | 月份中的第幾天（補零 01-31） | `23`                 |
| **`j`** | 月份中的第幾天（不補零 1-31） | `23`                 |
| **`S`** | 英文日期序數後綴          | `rd` (1st, 2nd, 3rd) |
| **`l`** | 完整的星期名稱 (小寫 L)    | `Monday`             |
| **`D`** | 三個字母的星期簡寫         | `Mon`                |
| **代碼**  | **說明**            | **範例輸出**             |
| **`H`** | 24 小時制（補零 00-23）  | `14`                 |
| **`G`** | 24 小時制（不補零 0-23）  | `14`                 |
| **`h`** | 12 小時制（補零 01-12）  | `02`                 |
| **`g`** | 12 小時制（不補零 1-12）  | `2`                  |
| **`i`** | 分鐘（補零 00-59）      | `01`                 |
| **`s`** | 秒數（補零 00-59）      | `15`                 |
| **`A`** | 大寫的上午/下午          | `PM`                 |
| **`a`** | 小寫的上午/下午          | `pm`                 |

---


|**特性**|**Function-Based View (FBV)**|**Class-Based View (CBV)**|
|---|---|---|
|**定義方式**|使用 Python 函數 (`def`)|使用 Python 類別 (`class`)|
|**程式碼結構**|邏輯線性，一目了然|邏輯分散在不同方法中 (如 `get`, `post`)|
|**可讀性**|**高** (適合處理複雜、獨特的邏輯)|**中** (需理解 Django 內部的調用順序)|
|**重複使用性**|**低** (通常透過輔助函數來共用程式碼)|**高** (透過繼承與 Mixins 輕鬆擴充)|
|**CRUD 開發速度**|較慢 (需手動處理所有步驟)|**極快** (使用內建的 Generic Views)|
|**HTTP 方法處理**|使用 `if request.method == 'POST':`|自動對應類別方法 `def post(self, ...):`|
|**URL 配置語法**|`path('...', views.my_view)`|`path('...', views.MyView.as_view())`|
```python
# pages/urls.py
from django.urls import path

from .views import home_page_view, AboutPageView

urlpatterns = [
    path("", home_page_view, name="home"),
    path("about", AboutPageView.as_view(), name="about")
]
```

```python
# pages/tests.py
from django.test import SimpleTestCase
from django.urls import reverse  # new


class HomepageTests(SimpleTestCase): # 靜態網頁測試
    def test_url_exists_at_correct_location(self): # 網址是否存在
        response = self.client.get("/")
        self.assertEqual(response.status_code, 200)

    def test_url_available_by_name(self):  # name 是否可用
        response = self.client.get(reverse("home"))
        self.assertEqual(response.status_code, 200)

    def test_template_name_correct(self):  # 確定使用正確的template
        response = self.client.get(reverse("home"))
        self.assertTemplateUsed(response, "home.html")

    def test_template_content(self):  # 確保網頁內容包含特定的文字或 HTML 標籤
        response = self.client.get(reverse("home"))
        self.assertContains(response, "<h1>Company Homepage</h1>")
```
