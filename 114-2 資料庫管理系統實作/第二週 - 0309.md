```
cd 
mkdir django # 創建資料夾
C: python -m pip install --upgrade pip # 更新pip
C: python -m venv .venv # 資料夾內建立虛擬環境
C: .venv\Scripts\activate # 開啟虛擬環境
(.venv) C: pip install django~=5.0.0 # 安裝django 版本 5.x.x
(.venv) C: deactivate # 出虛擬環境
```

```
(.venv) C: django-admin startproject django_project # 建立django 專案(會多一個資料夾)
|
|- django_project
 |
 |- django_project
  |
  |- ...
 |- manage.py
(.venv) C: django-admin startproject django_project . # 建立django 專案(使用原來資料夾)
|
|- django_project
 |
 |- ...
|- manage.py
```

```
(.venv) C: python manage.py runserver # 啟動django
(.venv) C: python manage.py migrate # 整理models.py 檔案，並依照該檔案建立資料庫

├── django_project
│   ├── __init__.py
|   ├── asgi.py
│   ├── settings.py
│   ├── urls.py
│   └── wsgi.py
├── db.sqlite3  # new
├── manage.py
```

```
(.venv) C: python manage.py startapp pages # 增加新的app

|
|-- django_project
|   |-- ...
├── pages
│   ├── __init__.py
│   ├── admin.py # 是內建 Django 管理應用程式的設定檔
│   ├── apps.py # 應用程式本身的設定檔
│   ├── migrations # 檔案變更
│   │   └── __init__.py
│   ├── models.py # 定義資料庫模型
│   ├── tests.py # 應用程式測試
│   └── views.py # 處理網頁應用請求/回應邏輯的地方
|-- manage.py
|-- ...
```
