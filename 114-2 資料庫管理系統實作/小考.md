## 基礎流程
1. 新建資料夾
```shell
mkdir django
```
2. 更新pip
```shell
python -m pip install --upgrade pip
```
3. 於資料夾內建立虛擬環境
```shell
cd django
python -m venv .venv
```
--- 
4. 開啟虛擬環境(以下皆在虛擬環境)
```shell
.venv\Scripts\activate
```
5. 安裝django(版本限定5.x.x)
```shell
pip install django~=5.0.0
```
6. 建立django 專案(名字是django_project，多一層資料夾)
```shell
django-admin startproject django_project
```
```shell
django-admin startproject django_project .
```
7. 整理models.py
```shell
python manage.py migrate
```
8. 啟動django server
```shell
python manage.py runserver
```

## APP 建立 (靜態網頁)
1. 增加新的app(名字為pages)
```shell
python manage.py startapp pages
```
```text
|
|-- django_project
|   |-- ...
├── pages
|   |-- templates
|   |   └── pages
|	|       |-- about.html
|	|       └── home.html
│   ├── __init__.py
│   ├── admin.py # 是內建 Django 管理應用程式的設定檔
│   ├── apps.py # 應用程式本身的設定檔
│   ├── migrations # 檔案變更
│   │   └── __init__.py
│   ├── models.py # 定義資料庫模型
│   ├── tests.py # 應用程式測試
│   ├── views.py # 處理網頁應用請求/回應邏輯的地方
|   └── urls.py # 自己建，url despatcher
|-- manage.py
|-- ...
```
2. 在專案設定新的app
```python
# django_project\settings.py
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'pages', # 新的自建的
]
```
3. app 中設定view
```python
# pages/views.py
from django.shortcuts import render
from django.views.generic import TemplateView  # new

# FBV
def home_page_view(request):
    context = {
        "inventory_list": ["Widget 1", "Widget 2", "Widget 3"],
        "greeting": "THAnk you FOR visitING.",
    }
    return render(request, "pages/home.html", context) 

# CBV
class AboutPageView(TemplateView):  # new
    template_name = "pages/about.html"

    def get_context_data(self, **kwargs):  # new
        context = super().get_context_data(**kwargs)
        context["contact_address"] = "123 Main Street"
        context["phone_number"] = "555-555-5555"
        return context
```
4. app 建立urls.py 並配置路徑
```python
# pages/urls.py
from django.urls import path

from .views import home_page_view, AboutPageView
# name 不必要，但可用於跳轉使用
urlpatterns = [
    path("", home_page_view, name="home"), # FBV
    path("about", AboutPageView.as_view(), name="about") #CBV
]
```
5. 配置專案urls 
```python
# django_project/urls.py
from django.contrib import admin
from django.urls import path, include  # new

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("pages.urls")),  # new
]
```

## APP建立 (動態網頁)
1. 建立新的app (名字為posts)
```shell 
python manage.py startapp pages
```
2. 定義資料表與欄位
```python
# 建立資料表(Post) 與欄位(text)
# posts/models.py
from django.db import models

class Post(models.Model):
	text = models.TextField()
```
3. 為posts 建立 migrate
```shell
python manage.py makemigrations posts
```
```Plaintext
# 執行結果
Migrations for 'posts':
posts/migrations/0001_initial.py
- Create model Post
```
4. 執行migrate
```shell
python manage.py migrate
```
```Plaintext
# 執行結果
Operations to perform:
Apply all migrations: admin, auth, contenttypes, posts, sessions
Running migrations:
Applying posts.0001_initial... OK
```
5. 建立超級使用者
```shell
python manage.py createsuperuser
```
```Plaintext
Username (leave blank to use 'wsv'):
Email:
Password:
Password (again):
Superuser created successfully.
```
6. 將Post 註冊到 Django 內建的後台管理系統
```python
# posts/admin.py
from django.contrib import admin
from .models import Post
admin.site.register(Post)
```
