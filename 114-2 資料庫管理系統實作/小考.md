## 基礎流程
1. 新建資料夾
```shell
mkdir django
```
2. 更新pip
```shell
python -m pip install --upgrade pip
```
3. 於資料夾內建立虛擬環境
```shell
cd django
python -m venv .venv
```
--- 
4. 開啟虛擬環境(以下皆在虛擬環境)
```shell
.venv\Scripts\activate
```
5. 安裝django(版本限定5.x.x)
```shell
pip install django~=5.0.0
```
6. 建立django 專案(名字是django_project，多一層資料夾)
```shell
django-admin startproject django_project
```
```shell
django-admin startproject django_project .
```
7. 整理models.py
```shell
python manage.py migrate
```
8. 啟動django server
```shell
python manage.py runserver
```

## APP 建立
1. 增加新的app(名字為pages)
```shell
python manage.py startapp pages
```
```text
|
|-- django_project
|   |-- ...
├── pages
│   ├── __init__.py
│   ├── admin.py # 是內建 Django 管理應用程式的設定檔
│   ├── apps.py # 應用程式本身的設定檔
│   ├── migrations # 檔案變更
│   │   └── __init__.py
│   ├── models.py # 定義資料庫模型
│   ├── tests.py # 應用程式測試
│   └── views.py # 處理網頁應用請求/回應邏輯的地方
|   |-- urls.py # 自己建，url despatcher
|-- manage.py
|-- ...
```
